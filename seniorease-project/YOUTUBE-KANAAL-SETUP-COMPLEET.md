## ✅ STAP 2: Branding (Visueel)

### 2.1 Profielfoto (Kanaal Avatar)
**YouTube Studio → Aanpassen → Branding → Profielfoto**

**Specificaties:**
- **Afmeting:** 800x800 pixels (vierkant)
- **Bestand:** `public/heart-logo.png` of maak nieuwe versie
- **Design:** SeniorEase hartlogo op witte of cream achtergrond
- **Zichtbaar:** Ook op kleine schermen (test op mobiel!)

**Check:**
- [ ] Logo is duidelijk zichtbaar
- [ ] Werkt op kleine schermen (test!)
- [ ] Geen tekst (wordt te klein)
- [ ] Hoog contrast voor duidelijkheid

---

### 2.2 Banner (Kanaal Art)
**YouTube Studio → Aanpassen → Branding → Banner**

**Specificaties:**
- **Afmeting:** 2048x1152 pixels (16:9 ratio)
- **Safe area:** Belangrijkste content in 1546x423 pixels (centrum)
- **Design template:** Zie hieronder

**Banner Design:**
```
┌─────────────────────────────────────────┐
│ [Logo]  SeniorEaseNL                   │
│                                         │
│    Handige technologie zonder gedoe     │
│                                         │
│    seniorease.nl                        │
│                                         │
│    [Subtiele achtergrond: cream/bruin] │
└─────────────────────────────────────────┘
```

**Kleuren:**
- Achtergrond: #F5EEE6 (cream) of gradient bruin
- Tekst: #8B5E3C (bruin) of #1F1F1F (donker)
- Logo: Prominent links

**Check:**
- [ ] Banner is 2048x1152 pixels
- [ ] Belangrijkste tekst in safe area (centrum)
- [ ] Logo duidelijk zichtbaar
- [ ] Website URL zichtbaar
- [ ] Test op desktop, tablet en mobiel

**💡 Tip:** Gebruik Canva template (zie `YOUTUBE-BANNER-CANVA-INSTRUCTIES.md`)

---

### 2.3 Watermark (Video Watermark)
**YouTube Studio → Aanpassen → Branding → Watermark**

**Specificaties:**
- **Afmeting:** 150x150 pixels (vierkant)
- **Bestand:** SeniorEase hartlogo (transparant PNG)
- **Positie:** Rechtsonder (standaard)
- **Weergave:** Laatste 15-60 seconden van video

**Check:**
- [ ] Logo is transparant (geen witte achtergrond)
- [ ] 150x150 pixels
- [ ] Test in video preview

## ✅ STAP 5: Kanaal Instellingen

### 5.1 Privacy & Beveiliging
**YouTube Studio → Instellingen → Kanaal → Privacy**

**Aanbevolen instellingen:**
- [ ] Kanaal is **Publiek** (niet privé of verborgen)
- [ ] Comments zijn **Toegestaan** (met moderatie optie)
- [ ] Community tab is **Ingeschakeld** (na 1000 abonnees)

---

### 5.2 Upload Defaults
**YouTube Studio → Instellingen → Upload defaults**

**Aanbevolen instellingen:**

**Privacy:**
- Standaard: **Publiek** (of Unlisted voor review, dan Public)

**Categorie:**
- Standaard: **Onderwijs** of **Hoe het werkt**

**Tags (standaard):**
```
SeniorEase, Senioren, Technologie, Nederland, Handig, Eenvoudig
```

**Check:**
- [ ] Standaard privacy ingesteld

- [ ] Standaard tags toegevoegd
