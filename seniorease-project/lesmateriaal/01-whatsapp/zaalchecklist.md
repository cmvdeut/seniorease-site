# Zaalchecklist — Lesmiddag WhatsApp

Print 1× voor de begeleider. Afvinken vóór en tijdens de middag.

## Ruimte

- [ ] Tafels of stoelen met armsteun; iedereen kan bij zijn telefoon
- [ ] Genoeg licht om het scherm te zien (geen felle tegenlicht)
- [ ] Bord, flipover of A4 voor wifi-wachtwoord en oefennummer begeleider
- [ ] Beamer / groot scherm (handig, niet verplicht)
- [ ] Koffie/thee (optioneel, welkom bij inloop)

## Techniek

- [ ] Wifi werkt; wachtwoord bekend
- [ ] Wifi kan 8–10 telefoons aan (test met 2–3 toestellen)
- [ ] Stopcontacten of stekkerdozen voor wie bijna leeg is
- [ ] Begeleider-telefoon opgeladen + WhatsApp werkt
- [ ] Helper heeft WhatsApp of kan meekijken

## Printwerk

- [ ] 1× draaiboek
- [ ] 8–10× deelnemerskaart
- [ ] 8–10× oefentaken (of dubbelzijdig met deelnemerskaart)
- [ ] 8–10× nazorgkaart
- [ ] Extra pennen (mensen noteren soms een tip)

## Mensen

- [ ] Begeleider aanwezig 20 min vóór start
- [ ] Helper aanwezig 15 min vóór start
- [ ] Max. 8–10 deelnemers (wachtlijst apart)
- [ ] Lijst met namen (voor noodgeval / brand / afwezigheid)

## Startzin klaarzetten

- [ ] Wifi-wachtwoord zichtbaar
- [ ] Telefoonnummer begeleider op het bord (voor oefenbericht), of afspraak “bericht naar buur”

## Na afloop

- [ ] Evaluatie begeleiders (zie ../pilot.md) — 30 min
- [ ] Eventuele fouten in knopnamen noteren → doorgeven voor versie 1.1
- [ ] Materialen opruimen; geen wachtwoorden op het bord laten staan
