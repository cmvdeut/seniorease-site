# Hulp bij vastlopen — E2: MijnOverheid gebruiken

**Pakket E** · Versie 2.0 · Voor begeleider en helper · Niet op de beamer

---

## Centrale vraag + volgorde

Eerst: **“Wat ziet u nu?”**

Daarna: vragen → uitleggen → aanwijzen → deelnemer zelf → pas als laatste kort overnemen.

---

## Situaties

| Situatie | Hulp |
|----------|------|
| Ik weet niet hoe ik MijnOverheid open | Typ mijnoverheid.nl zelf in de adresbalk · helper 1-op-1 · geen Google-les |
| MijnOverheid opent niet | Wifi · opnieuw typen · helper 1-op-1 · groep niet stilleggen |
| Ik zie Inloggen niet | Zoek “Inloggen met DigiD” · scherm kan anders zijn · helper wijst aan |
| Mijn scherm ziet er anders uit | Dat is normaal |
| Ik heb geen DigiD | Prima · les lukt via demolaag · geen aanvraag |
| Ik wil niet inloggen | Prima · niet verplicht |
| Ik weet mijn DigiD-wachtwoord niet | Niet klassikaal · niet hardop · helper apart of later IDO |
| Er wordt om een code gevraagd | Stop · vul niets in · groepsroute gaat niet zo ver |
| Ik zie de Berichtenbox niet | Gebruik het SeniorEase-oefenbeeld · helper vraagt “Wat ziet u nu?” |
| Ik ben niet ingelogd — hoe kan ik dan oefenen? | Via de demolaag · dat is genoeg voor deze les |
| Mijn persoonlijke MijnOverheid ziet er anders uit | Dat kan · demolaag is de groepsroute · echt alleen privé |
| Hoe ga ik terug? | Demolaag-route: kies zelf waar terug · helper vraagt “Waar gaat u terug?” · niet alleen pijl aanwijzen |
| Hoe sluit ik af? | Niet ingelogd: tabblad/app sluiten |
| Moet ik uitloggen? | Alleen als u echt bent ingelogd · anders sluiten |
| Mijn DigiD werkt niet | Niet klassikaal · doorverwijzen naar passende ondersteuning |
| Ik wil iets in een echt overheidsbericht vragen | Niet klassikaal · E4 / individueel / IDO — geen inhoud projecteren |

---

Echte persoonlijke inhoud: alleen individueel indien passend · nooit klassikaal projecteren/bespreken.

Geen paniektaal. Geen schaamte. Een uitzonderlijk toestel mag de groep niet stilleggen.
