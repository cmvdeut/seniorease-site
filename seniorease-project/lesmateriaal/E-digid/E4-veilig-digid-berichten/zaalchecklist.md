# Zaalchecklist

**E4 · Berichten van de overheid vinden en lezen** · Pakket E · Versie 2.0

Controleer vóór de les:

- [ ] Actuele openbare MijnOverheid-start gecontroleerd (mijnoverheid.nl)
- [ ] Inloggen met DigiD-label gecontroleerd
- [ ] Geen echte accounts nodig voor groepsles
- [ ] Neutrale SeniorEase-oefenomgeving / demolaag beschikbaar
- [ ] Demoberichten bevatten geen echte persoonsgegevens
- [ ] Oefenbericht A beschikbaar (Gemeente Oefenstad · bibliotheek)
- [ ] Eindmissiebericht B beschikbaar (Waterschap Oefenwater · fietspad)
- [ ] A en B duidelijk verschillend
- [ ] Oefenbijlagen neutraal (alleen herkennen · niet downloaden)
- [ ] Geen echte persoonlijke berichten projecteren
- [ ] Helper kent privacyregel (geen meekijken · geen codes)
- [ ] Telefoon/tablet én computer ondersteund
- [ ] Eindmissie exact 12 minuten beschermd
- [ ] Deelnemerskaarten aanwezig
- [ ] START HIER gelezen · hulpkaart paraat
- [ ] Beamer-PDF gereed
- [ ] Doorverwijsinformatie paraat (IDO / Digisterker / bibliotheek / organisatie)

**Afsluiten:** niet ingelogd → sluiten · wel → eerst uitloggen  
**E4 ≠ phishingles · ≠ downloadles**
