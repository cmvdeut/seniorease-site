# Hulp bij vastlopen

**E4 · Berichten van de overheid vinden en lezen** · Pakket E · Versie 2.0

**Start altijd:** “Wat ziet u nu?”  
**Volgorde:** vragen → uitleggen → aanwijzen → deelnemer zelf → pas laatste kort overnemen  

Helper leest **geen** persoonlijke berichten mee · vraagt geen wachtwoord/code · projecteert niets.

---

| Situatie | Hulp |
|----------|------|
| Ik heb een melding gekregen — wat nu? | Melding = seintje · open zelf MijnOverheid · zoek daar het bericht |
| Moet ik op de link in de melding klikken? | Voor deze oefening: nee · open MijnOverheid zelf |
| Waar vind ik MijnOverheid? | Typ mijnoverheid.nl zelf · helper 1-op-1 · geen Google-les |
| MijnOverheid opent niet | Wifi · opnieuw typen · helper 1-op-1 · groep niet stilleggen |
| Ik zie Inloggen met DigiD | Kijken / herkennen · niet invullen in de groepsroute |
| Ik heb geen DigiD | Prima · les lukt via de oefenomgeving |
| Mijn DigiD werkt niet | Niet klassikaal · doorverwijzen |
| Waar staat de Berichtenbox? | SeniorEase-oefenomgeving · helper wijst aan |
| Ik zie het oefenbericht niet | Helper 1-op-1 · “Wat ziet u nu?” · daarna kort aanwijzen |
| Hoe open ik een bericht? | Tik/klik op het afgesproken oefenbericht in het overzicht |
| Waar zie ik van wie het bericht komt? | Bij afzender / organisatie |
| Waar zie ik waar het bericht over gaat? | Bij onderwerp · daarna korte tekst |
| Ik zie een bestand/bijlage | Dat is de bijlage · herkennen · niet downloaden in de les |
| Moet ik de bijlage downloaden? | Nee · in deze les alleen herkennen |
| Hoe ga ik terug? | Terug in de oefenomgeving · “Waar gaat u terug?” |
| Moet ik uitloggen? | Alleen als u echt bent ingelogd · anders tabblad/app sluiten |
| Ik zie een echt persoonlijk bericht | Niet tonen · niet hardop · helper leest niet mee |
| Mag de helper mijn bericht lezen? | Nee · helper helpt alleen met bediening/route |
| Ik wil mijn echte bericht openen | OPTIONEEL · PRIVÉ · 1-OP-1 · groep wacht niet · niets projecteren |
| Ik begrijp mijn echte overheidsbrief niet | Niet gokken · afzender / IDO / Digisterker / bibliotheek / organisatie |
| Ik denk dat de melding nep is | Kort: open MijnOverheid zelf · meer → veiligheidslessen · E4 niet ombouwen |
| Mijn scherm ziet er anders uit | Dat is normaal |

Geen paniektaal. Geen schaamte.  
Begeleider is geen expert op overheidsbrieven.
