# Hulp bij vastlopen — E3: Iets regelen bij de digitale overheid

**Pakket E** · Versie 2.0 · Voor begeleider en helper · Niet op de beamer

---

## Centrale vraag + volgorde

Eerst: **“Wat ziet u nu?”**

Daarna: vragen → uitleggen → aanwijzen → deelnemer zelf → pas als laatste kort overnemen.

---

## Situaties

| Situatie | Hulp |
|----------|------|
| Ik weet niet waar ik moet beginnen | Open utrecht.nl · helper 1-op-1 · geen Google-les |
| De website opent niet | Wifi · opnieuw typen · helper 1-op-1 · groep niet stilleggen |
| Mijn scherm ziet er anders uit | Dat is normaal |
| Ik zie de afgesproken taak niet | Zoek op de site: taaknaam · of Online loket · “Wat ziet u nu?” |
| Ik kom op een andere pagina | Terug naar utrecht.nl · opnieuw zoeken binnen de site |
| Ik zie een zoekvak op de gemeentewebsite | Mag · zoek alleen de afgesproken taaknaam · geen zoekles |
| Ik zie Inloggen | Kijken / herkennen · niet invullen |
| Ik zie DigiD | Hier begint het persoonlijke deel · stop in de les |
| Er wordt om persoonlijke informatie gevraagd | Stop · vul niets in · oefening is klaar |
| Er wordt om mijn BSN gevraagd | Stop · vul niets in · nooit hardop |
| Er wordt om een betaling gevraagd | Stop · niet betalen |
| Moet ik nu verder? | Nee — u heeft gevonden waar u moet zijn · hier stopt de oefening |
| Ik wil dit echt aanvragen | Niet in de les · thuis / IDO / gemeente |
| Mijn eigen gemeente ziet er anders uit | Dat is normaal · Utrecht is oefenvoorbeeld |
| Ik wil de taak bij mijn eigen gemeente vinden | OPTIONEEL · 1-op-1 · groep wacht niet · geen echte aanvraag |
| Ik heb geen DigiD | Prima · les lukt zonder DigiD |
| Mijn DigiD werkt niet | Niet klassikaal · doorverwijzen |
| Ik heb een inhoudelijke vraag over de regeling | Niet gokken · officiële organisatie / IDO / Digisterker / bibliotheek |

Geen paniektaal. Geen schaamte. Een uitzonderlijk toestel mag de groep niet stilleggen.
