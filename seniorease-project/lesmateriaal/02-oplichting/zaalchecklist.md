# Zaalchecklist — Lesmiddag Oplichting herkennen

## Ruimte

- [ ] Stoelen in groep of U-vorm (makkelijk praten)
- [ ] Bord of flipover voor de drie stappen bij twijfel
- [ ] Beamer optioneel (niet nodig)
- [ ] Koffie/thee optioneel

## Techniek

- [ ] Wifi **niet verplicht** (liever geen links openen)
- [ ] Geen QR-codes naar “oefenlinks” uitdelen
- [ ] Voorbeeldkaarten geprint (oefentaken A–F), 1 set per deelnemer of per tweetal

## Printwerk

- [ ] 1× draaiboek
- [ ] 8–10× deelnemerskaart
- [ ] 8–10× oefentaken (zonder antwoordsleutel op de deelnemersprint — of sleutel apart voor begeleider)
- [ ] 8–10× nazorgkaart
- [ ] Extra pennen

## Mensen

- [ ] Begeleider 20 min voor start
- [ ] Helper 15 min voor start (vooral bij emotionele verhalen)
- [ ] Max. 8–10 deelnemers
- [ ] Weten waar IDO / SeniorWeb-spreekuur is als iemand DigiD-hulp wil

## Toon bewaken

- [ ] Geen paniekzaaierij
- [ ] Geen schaamte als iemand ooit getrapt is
- [ ] Kort houden bij lange persoonlijke verhalen (“Dank u — dat is precies waarom we oefenen”)

## Na afloop

- [ ] Evaluatie begeleiders (30 min)
- [ ] Geen wifi-wachtwoorden of oefennummers laten staan (n.v.t. meestal)
