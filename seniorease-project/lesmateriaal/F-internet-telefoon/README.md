# Pakket F — Internet (telefoon/tablet)

Vier lessen voor **eigen telefoon of tablet** + wifi. Geen bord/beamer.

**Begeleiders:** [begeleiders-en-vrijwilligers.md](../begeleiders-en-vrijwilligers.md)

| Les | Onderwerp | Status |
|-----|-----------|--------|
| Ft1 | Zoeken | klaar |
| Ft2 | Browser gebruiken | klaar |
| Ft3 | QR-codes openen | klaar |
| Ft4 | Formulieren en downloads terugvinden | klaar |

**Computer-variant:** zie later `F-internet-computer` (Fc1–Fc4).

## Bouwen

```bash
cd lesmateriaal/F-internet-telefoon
python build_all.py
```

Of per les:

```bash
python Ft1-zoeken/build_pdf.py
```

PDF: `Ft1-zoeken/pdf/SeniorEase-Ft1-Zoeken-v1.pdf`

## Stijl

Zelfde als A/C/D/E: Kijken → Doen → Controleren → Pauzeren op het eigen toestel.

Legacy `03-google-maps` combineerde zoeken + Maps; Ft1 is alleen **zoeken**. Maps kan later als bonus.
