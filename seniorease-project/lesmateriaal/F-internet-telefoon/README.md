# Pakket F — Internet (telefoon/tablet)

Vier lessen voor **eigen telefoon of tablet** + wifi. Geen bord/beamer. Max. 8–10 deelnemers.

**F-computer** = internet met muis/toetsenbord · **F-telefoon/tablet** = internet met aanraken, mobiele browser, QR en mobiele formulieren.
