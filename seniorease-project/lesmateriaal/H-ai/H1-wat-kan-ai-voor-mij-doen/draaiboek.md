# Draaiboek — H1: Wat kan AI voor mij doen?

**Pakket H — AI in het dagelijks leven · Versie 2.0**  
**Duur:** ca. 90 minuten (inloop **buiten** de lestijd)  
**Functie:** ONTDEKKEN · **Rode draad:** AI kan mij helpen  
**Begeleiding:** 1 begeleider + 1 helper | **Max:** 8–10  
**Apparaat:** telefoon, tablet of computer · browser → Gemini-web (voorbeeld)  
**Zaal:** Beamer + print. Deelnemers oefenen daarna zelf (of Route B/C).

---

## Rollen

| Rol | Wat u doet |
|-----|------------|
| **Begeleider** | Beamer · demo · tempo · groep |
| **Helper** | 1-op-1 · “Wat ziet u nu?” · Route B/C |

Helper: vragen → uitleggen → aanwijzen → deelnemer doet → pas laat overnemen.  
2-minutenregel: daarna individueel / parkeren.

---

## Demotekst (exact · fictief · geen PII)

> Geachte bezoeker,  
> Vanwege werkzaamheden is de leeszaal van 12 tot en met 16 mei beperkt toegankelijk. Wij adviseren u vóór uw bezoek op onze website te controleren of de leeszaal geopend is. De overige ruimtes van de bibliotheek blijven volgens de normale openingstijden toegankelijk.

**Demo-vraag:** Leg deze tekst uit in gewone taal.  
**Bijsturing:** Nog korter, alstublieft.  
*(Als al heel kort: Leg het uit in drie eenvoudige zinnen.)*

**Voorbeeldantwoord (alleen begeleider · niet op eindmissie-dia):**  
*Van 12 tot 16 mei is de leeszaal minder open door werkzaamheden. Kijk vóór uw bezoek op de website of de leeszaal open is. De rest van de bibliotheek is gewoon open.*

**Korter voorbeeld:**  
*Leeszaal 12–16 mei beperkt open. Check de website vóór u komt. De rest van de bibliotheek is gewoon open.*

## Oefenkaarten A–D

| | Start | Bijsturing |
|--|-------|------------|
| **A Uitleggen** | Leg dit eenvoudiger uit. *(demotekst)* | Nog korter, alstublieft. |
| **B Ideeën** | Wat kan ik maken met aardappelen, broccoli en eieren? | Geef mij drie mogelijkheden. |
| **C Formuleren** | Maak dit vriendelijker: Ik kom morgen wat later. | Nog iets vriendelijker. |
| **D Stappen/mogelijkheden** | Geef mij drie ideeën voor een eenvoudige verjaardag thuis. | Maak ze korter. |

## Tijdlijn (indicatief · start na inloop)

### 0–10 — Welkom + situatie

| | |
|--|--|
| **Doel** | Behoefte eerst — geen “Wat is AI?” |
| **Zegt u** | “Stel: u krijgt een tekst die u niet meteen duidelijk vindt.” Toont demotekst. “Wat zou u hiermee willen?” |
| **Laat zien** | Demotekst groot op beamer |
| **Deelnemer** | Reageert kort (begrijpen / weten of open / …) |
| **Helper** | Luistert · nog niet technisch helpen |
| **Verder als** | Groep de situatie herkent |

### 10–20 — Eerste AI-ervaring

| | |
|--|--|
| **Doel** | TEKST → GEWONE TAAL zien |
| **Zegt u** | “Leg deze tekst uit in gewone taal.” · daarna: “Dit is één van de dingen waarbij AI kan helpen.” |
| **Demonstreert** | Gemini-web (voorbeeld) · vraag · antwoord |
| **Deelnemer** | Kijkt · leest antwoord |
| **Helper** | Klaar voor vastlopers later |
| **Vast?** | Zie Hulp: cookie · scherm anders |
| **Verder als** | Antwoord zichtbaar geweest |

### 20–25 — Kort bijsturen

| | |
|--|--|
| **Doel** | Eerste antwoord ≠ eindpunt |
| **Zegt u** | “Nog korter, alstublieft.” |
| **Demonstreert** | Eén vervolgvraag · korter antwoord |
| **Niet** | Nieuw gesprek · knoppen uitleggen (H2) |

### 25–30 — Korte uitleg AI

| | |
|--|--|
| **Doel** | Max. ca. 5 min · ná ervaring |
| **Zegt u** | AI-assistent = programma voor antwoord/uitleg/idee. Denkt niet als mens. Antwoord kan fout zijn. “In deze les gebruiken we Google Gemini als voorbeeld. Andere AI-assistenten werken op veel punten vergelijkbaar.” |

### 30–42 — Vier soorten hulp

| | |
|--|--|
| **Doel** | Uitleggen · ideeën · formuleren · stappen/mogelijkheden |
| **Laat zien** | Beamer A–D (icoon + woord) |
| **Zegt u** | Kort voorbeeld per categorie · koelkast als lichte brug bij B |
| **Verder als** | Groep minstens twee soorten kan noemen |

### 42–57 — Zelf ervaren ronde 1

| | |
|--|--|
| **Doel** | Eén veilige vraag ervaren |
| **Zegt u** | “Kies A, B, C of D. Geen geheimen typen.” Tip: antwoord kan fout zijn. |
| **Deelnemer** | Kiest · Route A/B/C · bekijkt antwoord |
| **Helper** | “Wat ziet u nu?” · Route C: deelnemer dicteert |
| **Verder als** | Meesten een antwoord hebben gezien |

### 57–62 — Kort delen

| | |
|--|--|
| **Zegt u** | “Wat vond u bruikbaar?” — geen schoolse rondvraag |

### 62–72 — Ronde 2 / bijsturing

| | |
|--|--|
| **Doel** | Eén kleine verbetering |
| **Deelnemer** | Bijsturing van de kaart |
| **Bij tijdnood** | Inkorten · eindmissie beschermen |

### 72–84 — Eindmissie (ca. 10–12 min)

| | |
|--|--|
| **Situatie** | “U wilt hulp bij een gewone dagelijkse vraag.” |
| **Deelnemer** | 1 Kies situatie · 2 Bepaal wat AI doet · 3 Bekijk antwoord · 4 Eén verbetering · 5 Bruikbaarder? |
| **Succes** | “Hier kan AI mij bij helpen.” + eigen keuzes voor vraag/bijsturing |
| **Begeleider** | **Geen voordoen** · geen voorbeeldantwoord op beamer |
| **Helper** | Alleen vaste methode |

### 84–90 — Afronding

| | |
|--|--|
| **Zegt u** | “Vandaag hebt u gezien en ervaren dat AI kan helpen bij gewone vragen en taken. De volgende keer leert u hoe u zelf een gesprek met een AI-assistent voert.” |

---

## Als de tijd krap is

**Niet schrappen:** situatie + TEKST→GEWONE TAAL + één bijsturing + zelf ervaren + eindmissie.
