# Hulp bij vastlopen — H1 Wat kan AI voor mij doen?

**Pakket H · Versie 2.0 · Alleen begeleider/helper**

**Vaste volgorde:** “Wat ziet u nu?” → vragen → uitleggen → aanwijzen → deelnemer doet/stuurt → pas als laatste kort overnemen.

| Situatie | Wat u doet |
|----------|------------|
| **Kan niet inloggen / geen account** | Route **B** (zaaltoestel) of **C** (stuur-meekijk). Geen account aanmaken. Geen wachtwoorden. |
| **Weet niet wat te vragen** | “Kies A, B, C of D.” Toon oefenkaarten. |
| **Cookievenster** | “Dit hoort niet bij onze oefening. Ik help u dit venster eerst weg te krijgen.” Deelnemer tikt zelf. Geen cookieles. |
| **Scherm ziet er anders uit** | “Uw scherm kan er iets anders uitzien. Dat is normaal.” |
| **Antwoord is erg lang** | “Vraag: Nog korter, alstublieft.” |
| **Antwoord is vreemd / onbruikbaar** | Niet uitgebreid corrigeren. Kies eenvoudige bijstuurvraag of andere kaart. |
| **Route C — wie bepaalt?** | Deelnemer kiest vraag én bijsturing en dicteert. U bedient alleen wat nodig is. |
| **Vastloper > ca. 2 minuten** | Helper individueel of parkeren. Groep gaat verder. |
| **Wil privéprobleem typen** | “Kies vandaag een veilige oefening van de kaart. Geen geheimen.” |
| **Vraagt om app te installeren** | “Niet nodig in deze les. We gebruiken de browser.” |

Afwijkend apparaat mag de groep niet stilzetten.
