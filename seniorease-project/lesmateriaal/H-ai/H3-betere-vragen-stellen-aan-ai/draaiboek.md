# Draaiboek — H3: Betere vragen stellen aan AI

**Pakket H · Versie 2.0** · ca. **90 min** (inloop buiten) · max. 8–10 · begeleider + helper  
**Functie:** VERBETEREN · **Route:** WAT WILT U? → GEEF WAT INFORMATIE → ZEG HOE U HET WILT

## Demo (exact)

**VOOR:** Wat kan ik koken?  

**NA:** Geef mij drie ideeën voor een eenvoudige avondmaaltijd. Ik heb aardappelen, broccoli en eieren in huis. Geef per idee maximaal drie korte stappen.

---

## Oefenronde 1

Vage: *Wat kan ik doen?* · Situatie: het regent · thuis ontspannen.  
Samen: WAT / INFO / HOE (frozen zinnen).

## Oefenkaarten A–D

| | Begin | Richting |
|--|-------|----------|
| **A** | Wat kan ik eten? | Brood, ei, tomaat |
| **B** | Schrijf een bericht. | Buurman: morgen niet thuis · vriendelijk |
| **C** | Wat is wifi? | Gewone taal |
| **D** | Verjaardag | Drie eenvoudige ideeën thuis |

---

### 0–5 — H2-retrieval

| | |
|--|--|
| **Doel** | Vraag → antwoord → vervolg ophalen · geen bedieningsles |
| **Zegt u** | “Waar typt u uw vraag?” · “Wat doet u als u nog iets wilt weten?” |
| **Deelnemer** | Antwoordt kort |
| **Brug** | “U weet hoe u AI bedient. Vandaag: vraag duidelijker maken.” |

### 5–10 — Startsituatie

| | |
|--|--|
| **Toont** | “Wat kan ik koken?” + kort antwoord |
| **Vraagt** | “Is dit antwoord bruikbaar?” |
| **Check** | Groep merkt: AI weet nog weinig |

### 10–18 — WAT WILT U?

| | |
|--|--|
| **Doel** | Duidelijk zeggen waarvoor hulp |
| **Demonstreert** | “Geef mij drie ideeën voor een eenvoudige avondmaaltijd.” |
| **Helper** | “Wat wilt u precies weten?” |

### 18–26 — GEEF WAT INFORMATIE

| | |
|--|--|
| **Doel** | Alleen veilige, nodige info |
| **Demonstreert** | … aardappelen, broccoli en eieren |
| **Zegt u** | “Niet alles delen. Geen geheimen.” |

### 26–34 — ZEG HOE U HET WILT

| | |
|--|--|
| **Doel** | Hoe het antwoord eruit mag zien |
| **Demonstreert** | … maximaal drie korte stappen |
| **Regel** | “Niet altijd alle drie nodig.” |

### 34–40 — Voor/na

| | |
|--|--|
| **Toont** | VOOR vs NA groot op beamer |
| **Vraagt** | “Welke vraag helpt AI het meest?” |
| **Niet** | “Dus het antwoord is waar” (H4) |

### 40–49 — Oefenronde 1

Samen regen/thuis · mondeling bouwen · daarna AI.

### 49–60 — Oefenronde 2

Kaarten A–D · tweetallen · helper: WAT/INFO/HOE-vragen · niet vóórformuleren.

### 60–68 — Oefenronde 3

Zelf: gewone vraag → verbeteren met minstens één element → vergelijken.

### 68–80 — Eindmissie (10–12)

Zelfstandig: gewone vraag → minstens twee van WAT/INFO/HOE → vergelijken → “Dit past beter omdat…”  
Route B/C: deelnemer formuleert; bij C mag helper noodzakelijke bediening (H2-contract).

### 80–85+ — Afronding

Thuis: één vraag duidelijker maken. Brug H4: controleren komt later.
