# Draaiboek — H2: Een AI-assistent gebruiken

**Pakket H — AI in het dagelijks leven · Versie 2.0**  
**Duur:** ca. 90 minuten (inloop **buiten** de lestijd)  
**Functie:** BEDIENEN · **Rode draad:** Ik kan AI zelf gebruiken  
**Begeleiding:** 1 begeleider + 1 helper | **Max:** 8–10  
**Apparaat:** browser → `gemini.google.com` (voorbeeld)  
**Zaal:** Beamer + print. Deelnemers oefenen zelf (of Route B/C).

---

## Rollen

| Rol | Wat u doet |
|-----|------------|
| **Begeleider** | Beamer · demo · tempo · groep |
| **Helper** | 1-op-1 · “Wat ziet u nu?” · Route B/C |

Helper: vragen → laten aanwijzen → één tip → deelnemer doet → pas laat overnemen.  
**~2-minutenregel:** daarna individueel / fallback · groep gaat verder.

---

## Kaderzin (één keer)

> In deze les gebruiken we Gemini.  
> Andere AI-assistenten, zoals ChatGPT en Copilot, werken op een vergelijkbare manier.

## Demo (exact)

**Situatie:** U wilt vanavond iets makkelijks koken. U heeft aardappelen, broccoli en eieren.

**Vraag:** Geef mij drie eenvoudige ideeën voor een maaltijd met aardappelen, broccoli en eieren.  
**Vervolgvraag:** Welke is het makkelijkst?  
*(of: Leg nummer 2 in drie stappen uit.)*

## Oefenronde 1 (exact · frozen)

**Startvraag:** Geef mij drie ideeën voor een gezellige middag thuis.  
**Vervolgvraag:** Welke is het makkelijkst om te organiseren?

## Keuzekaarten A–D (oefenronde 2)

| | Thema | Startvraag | Vervolgvraag |
|--|-------|------------|--------------|
| **A** | ETEN | Geef mij drie ideeën voor een eenvoudige lunch. | Maak het korter. / Welke zou u als eerste kiezen? |
| **B** | UITJE | Wat kan ik op een regenachtige middag thuis doen? | Geef nog twee ideeën. |
| **C** | BERICHT | Maak deze zin iets vriendelijker: Ik kan donderdag niet komen. | Maak het korter. |
| **D** | UITLEG | Leg uit wat een QR-code is in eenvoudige woorden. | Leg het nog eenvoudiger uit. |

## Tijdlijn (indicatief · start na inloop)

### 0–8 — Welkom + H1-retrieval (5–8 min)

| | |
|--|--|
| **Situatie** | Terug naar H1: waar AI kan helpen |
| **Doel** | Herkenning · geen bediening |
| **Zegt u** | Drie situaties: eenvoudiger uitleg · ideeën · bericht formuleren. “Waar zou AI u bij kunnen helpen?” |
| **Laat zien** | Beamer: drie situaties |
| **Demonstreert** | Niets technisch |
| **Deelnemer** | Kiest één situatie · zegt ongeveer wat hij/zij zou vragen |
| **Tijd** | 5–8 min |
| **Check** | Iedereen heeft iets kunnen noemen |
| **Helper** | Luistert |
| **Doorgaan als** | Brugzin gezegd: “Vorige keer zagen we waar AI bij kan helpen. Vandaag gaat u het zelf bedienen.” |
| **Hulp** | — |

### 8–13 — Startsituatie (5 min)

| | |
|--|--|
| **Situatie** | Koelkast / makkelijk koken |
| **Doel** | Behoefte eerst · niet browser-theorie |
| **Zegt u** | “U wilt vanavond iets makkelijks koken. U heeft aardappelen, broccoli en eieren.” |
| **Laat zien** | Situatiedia |
| **Deelnemer** | Herkent de situatie |
| **Tijd** | 5 min |
| **Doorgaan als** | Groep de behoefte begrijpt |

### 13–23 — OPENEN / herkennen (10 min)

| | |
|--|--|
| **Doel** | Browser · Gemini-web · “Hier typ ik mijn vraag” |
| **Zegt u** | Kaderzin Gemini. URL: gemini.google.com. “Uw scherm kan er iets anders uitzien. Dat is normaal.” |
| **Demonstreert** | Browser openen · Gemini bereiken · typvak aanwijzen |
| **Deelnemer** | Zoekt typvak (of wijst bij Route C) |
| **Helper** | “Wat ziet u nu?” |
| **Check** | Deelnemer kan aanwijzen: typvak |
| **Hulp** | A · D · H |
| **Doorgaan als** | Typvak herkend |

### 23–33 — Eerste VRAGEN (10 min)

| | |
|--|--|
| **Doel** | Typen · vóór verzenden kijken · versturen |
| **Zegt u** | Demo-vraag voorlezen. “Kijk eerst kort. Daarna versturen.” |
| **Demonstreert** | Typen · verzendknop/-teken |
| **Deelnemer** | Ziet handeling · nog niet iedereen zelf (dat komt bij oefenen) |
| **Check** | Verzendhandeling herkend |
| **Hulp** | B · C |
| **Niet** | Prompt verbeteren (H3) |

### 33–40 — ANTWOORD LEZEN (7 min)

| | |
|--|--|
| **Doel** | Antwoord herkennen · eventueel scrollen |
| **Zegt u** | “Dit is het antwoord van AI. Het kan langer zijn dan één scherm.” “Een AI-antwoord kan een fout bevatten.” |
| **Demonstreert** | Kort antwoord · scrollen indien nodig |
| **Deelnemer** | Leest mee |
| **Check** | Antwoord zichtbaar geweest |
| **Hulp** | E |

### 40–50 — DOORVRAGEN (10 min)

| | |
|--|--|
| **Doel** | Zelfde gesprek · verder vragen werkt |
| **Zegt u** | “Welke is het makkelijkst?” · “AI kan in hetzelfde gesprek rekening houden met wat u net heeft gevraagd.” |
| **Demonstreert** | Vervolgvraag → vervolgantwoord |
| **Deelnemer** | Ziet dat opnieuw beginnen niet nodig is |
| **Check** | Vervolgantwoord zichtbaar |
| **Hulp** | F |
| **Niet** | WAT / INFO / HOE (H3) |

### 50–57 — NIEUW GESPREK (7 min)

| | |
|--|--|
| **Doel** | Ander onderwerp → nieuw gesprek · leeg typvak |
| **Zegt u** | “Nu wilt u een idee voor een verjaardagscadeau. Hoort dit nog bij hetzelfde onderwerp?” |
| **Demonstreert** | Nieuw gesprek starten · leeg typvak |
| **Deelnemer** | Herkent de knop/handeling |
| **Check** | Leeg typvak herkend |
| **Hulp** | G |
| **Niet** | Chatgeschiedenis-beheer |

### 57–69 — Oefenronde 1 — samen (12 min)

| | |
|--|--|
| **Doel** | Iedereen dezelfde veilige basishandeling |
| **Zegt u** | Startvraag + vervolgvraag (frozen · zie boven) |
| **Deelnemer** | Bereikt AI → typvak → typen → kijken → versturen → lezen → vervolgvraag |
| **Helper** | “Wat ziet u nu?” |
| **Fallback** | B/C bij login · 2-minutenregel |
| **Doorgaan als** | Meeste deelnemers hebben vervolgvraag gesteld (of gestuurd via C) |

### 69–81 — Oefenronde 2 — meer zelf (12 min)

| | |
|--|--|
| **Doel** | Zelf kiezen · bediening oefenen |
| **Zegt u** | “Kies A, B, C of D. Geen privégegevens.” |
| **Deelnemer** | Startvraag + eenvoudige vervolgvraag |
| **Helper** | Individueel · fallback |
| **Bij tijdnood** | Inkorten · **eindmissie beschermen** |

### 81–93 — Eindmissie (10–12 min)

| | |
|--|--|
| **Doel** | Zelfstandig bedienen zonder voordoen |
| **Zegt u** | “Doe dit zelf. Geen toets.” |
| **Deelnemer** | 1 openen · 2 veilige vraag · 3 versturen · 4 lezen · 5 vervolgvraag · 6 lezen · 7 nieuw gesprek · 8 opnieuw beginnen herkennen |
| **Succes** | “Hier typ ik mijn vraag.” + versturen · antwoord · vervolg · nieuw gesprek |
| **Route B/C** | Deelnemer stuurt, kiest, dicteert, wijst |
| **Helper** | Alleen vaste methode · geen herdemonstratie |

### 93–90+ — Afronding (4–7 min · past binnen 90)

| | |
|--|--|
| **Zegt u** | “U weet waar u typt en u durft verder te vragen.” Thuis: één gewone vraag + één vervolg. “Volgende keer: betere vragen stellen (H3).” |
| **Niet** | Schoolse toets |

## Als de tijd krap is

Niet schrappen: openen · eerste vraag · antwoord · doorvragen · **eindmissie**.  
Nieuw gesprek kort houden. Oefenronde 2 inkorten.

## Privacy

Gebruik in de oefening geen privégegevens.
