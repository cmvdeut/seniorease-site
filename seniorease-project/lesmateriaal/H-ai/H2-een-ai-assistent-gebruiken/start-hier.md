# START HIER — voor de begeleider

**H2 · Een AI-assistent gebruiken · Pakket H · Versie 2.0**  
Lees dit blad eerst. Voorbereiding circa 10–15 minuten.

---

## Belofte

Ik kan zelf een AI-assistent openen, een vraag stellen, het antwoord lezen, doorvragen en een nieuw gesprek beginnen.

## Functie vandaag

**BEDIENEN** · Rode draad: **Ik kan AI zelf gebruiken.**

Route: **OPENEN → VRAGEN → ANTWOORD LEZEN → DOORVRAGEN**  
Aanvullend: **Nieuw onderwerp? → Start een nieuw gesprek**

## Wat deelnemers zelf gaan doen

- Browser openen · `gemini.google.com` bereiken  
- Typvak vinden · vraag typen · kort bekijken · versturen  
- Antwoord lezen · één vervolgvraag stellen  
- Nieuw gesprek herkennen/starten  
- Eindmissie zelfstandig (Route A, of sturen via B/C)

## Groep

Max. circa **8–10** deelnemers.  
**Begeleider + helper** aanbevolen.

## Vooraf klaarzetten (10–15 min)

- [ ] Internet getest  
- [ ] Beamer getest  
- [ ] Browser beschikbaar  
- [ ] **gemini.google.com** vooraf getest  
- [ ] Actuele route/URL op A4  
- [ ] Fallbackapparaat(en) indien mogelijk **vooraf open** op Gemini  
- [ ] Keuzekaarten A–D klaar  
- [ ] Geen klassikale accountcreatie gepland  

## Fallback A / B / C

| Route | Wat |
|-------|-----|
| **A** | Eigen apparaat · browser → Gemini-web |
| **B** | Voorbereid les-/ruimteapparaat · al open · geen wachtwoord in de les |
| **C** | Deelnemer bepaalt en dicteert · begeleider/helper typt alleen wat gezegd wordt |

**~2-minutenregel:** individueel probleem langer dan ca. 2 min → helper 1-op-1 / fallback · **groep gaat verder**.

## Account / login

- Geen klassikale accountcreatie  
- Geen wachtwoorden of codes vragen / opschrijven / op beamer  
- Login is **geen** leerdoel · bij inlogmelding → Route B of C  

## Helper

Begin altijd met: **“Wat ziet u nu?”**  
Daarna: laten aanwijzen → één kleine tip → deelnemer doet zelf → pas laat overnemen.

## Schermen

Uw scherm kan er iets anders uitzien. Dat is normaal.  
Leer herkenning op functie: *“Waar typ ik mijn vraag?”*

## Gemini (voorbeeld)

> In deze les gebruiken we Gemini.  
> Andere AI-assistenten, zoals ChatGPT en Copilot, werken op een vergelijkbare manier.

H2 is **geen** Gemini-productcursus.

## Privacy (kort)

Gebruik in de oefening geen privégegevens.  
Een AI-antwoord kan een fout bevatten. *(Uitgebreide controle = H4.)*
