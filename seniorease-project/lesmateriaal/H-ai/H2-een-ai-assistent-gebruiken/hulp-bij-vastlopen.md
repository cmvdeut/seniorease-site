# Hulp bij vastlopen — H2

**Alleen begeleider/helper.** Begin altijd met: **“Wat ziet u nu?”**

Volgorde: vragen → laten aanwijzen → één tip → deelnemer doet → pas laat overnemen.  
Account/login: **geen wachtwoord vragen**. Ca. **2 minuten** → individueel / fallback B of C → **groep gaat verder**.
