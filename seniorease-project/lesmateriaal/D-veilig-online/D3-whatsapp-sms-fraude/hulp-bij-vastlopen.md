# D3 — Hulp bij vastlopen

Voor begeleider en helper. Niet op de beamer. Versie 2.0.

## Centrale vraag + volgorde

Eerst: **“Wat ziet u nu?”**  
Daarna: vragen → uitleggen → aanwijzen → deelnemer doet zelf → pas als laatste kort overnemen.

---

| Situatie | Hulp |
|----------|------|
| Is deze beller echt van de bank? | U hoeft dat niet te bewijzen · eerst STOP / beëindigen · alleen indien nodig zelf controleren |
| Er staat een bekende naam of nummer | Bewijst niet wie belt · toch stoppen |
| Mag ik de code doorgeven? | Nee bij onverwachte beller/helpdesk |
| Mag ik die app installeren / scherm delen? | Nee · GEEN SOFTWARE · GEEN SCHERM |
| Welk nummer moet ik bellen? | Zoek zelf via een route die u al vertrouwt — niet uit het gesprek of bericht |
| Staat het nummer al in Contacten — is dat genoeg? | Nee · Contacten ≠ automatisch officiële route |
| Moet ik ieder onverwacht telefoontje terugbellen? | Nee · eerst beëindigen · alleen als u dat nodig vindt |
| Ik vind mijn bank-app niet | Helper 1-op-1 · iPhone \| Android · “Uw scherm kan anders zijn” |
| Mag ik echt de bank bellen in de les? | Nee — oefen de zin en de officiële route tot startscherm / gecontroleerd nummer / site |
| Dit lijkt op familie met nieuw nummer | Dat hoort bij C4 · vandaag helpdesk/beller |
| “Veilige rekening” — moet ik overmaken? | Nee · stoppen · niet betalen |
| Ik heb al iets gezegd / bijna gedaan | Stop vanaf nu · helper 1-op-1 · geen schaamte |
| Afwijkend toestel | Helper 1-op-1 — groep niet stilleggen |
| Echt verdacht telefoontje / bericht | Niet op beamer · helper 1-op-1 · niet meewerken · bij ernst: officiële hulp / organisatie |

Geen paniektaal. Geen schaamte. Geen volledige fraudeherstelprocedure.
