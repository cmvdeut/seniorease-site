# Deelnemerskaart — D3 Oplichters aan de telefoon en via berichten

Mee naar huis. Thuis binnen enkele seconden bruikbaar. Versie 2.0.

---

## Bij een onverwachte beller of helpdesk

**ONVERWACHTE HULP?**  
→ **STOP**  
→ **ZELF TERUGBELLEN**

### Ook

**STOP** → **NIET VERDERGAAN** → **ZELF CONTROLEREN**

### Doe dit niet

- NIET BETALEN  
- GEEN CODE DELEN  
- NIET OP EEN ONVERWACHTE LINK TIKKEN  
- GEEN SOFTWARE INSTALLEREN  
- GEEN SCHERM DELEN  

### Zeg dit

> “Ik bel u zelf terug via het officiële nummer.”

### Let op

- Eerst het onverwachte contact beëindigen.  
- Niet ieder onverwacht gesprek hoeft te worden teruggebeld.  
- Alleen terugbellen / controleren als u dat nodig vindt.  
- Nooit via het nummer uit het gesprek of bericht.  

### Zelf

- Zoek zelf het officiële nummer via een route die u al vertrouwt.  
- Bijvoorbeeld: officiële app · eerder gecontroleerd officieel nummer · officiële site die u zelf opent.  
- Niet: willekeurig contact omdat het in Contacten staat.  

### Dit kan ik nu

- [ ] Een onverwacht gesprek of helpdeskbericht stopzetten  
- [ ] Geen code / software / scherm toestaan  
- [ ] De terugbelzin zeggen (als controleren nodig is)  
- [ ] Zelf een officiële route kiezen die ik al vertrouw
