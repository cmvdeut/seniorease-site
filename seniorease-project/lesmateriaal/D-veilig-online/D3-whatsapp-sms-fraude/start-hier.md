# START HIER — voor de begeleider

**D3 · Oplichters aan de telefoon en via berichten** · Pakket D · Versie 2.0  
**Ondertitel:** Gesprek stoppen, geen code of scherm delen, en zelf terugbellen

Lees dit blad eerst. Voorbereiding circa 10–15 minuten.

---

## U hoeft niet te bewijzen dat iemand een fraudeur is

U begeleidt. Doel: veilig gedrag bij twijfel.

**Pakketkapstok:** STOP → NIET VERDERGAAN → ZELF CONTROLEREN  
**D3-kapstok:** ONVERWACHTE HULP? → STOP → ZELF TERUGBELLEN  
**Extra:** GEEN SOFTWARE INSTALLEREN · GEEN SCHERM DELEN  
**Risico’s:** NIET BETALEN · GEEN CODE DELEN · NIET OP EEN ONVERWACHTE LINK TIKKEN

**Terugbelzin:** “Ik bel u zelf terug via het officiële nummer.”  
Eerst beëindigen · alleen terugbellen als controleren nodig is · nooit via nummer uit het gesprek/bericht.

---

## Wat leert de deelnemer?

Stoppen bij een onverwachte beller of helpdesk, geen code/software/scherm toestaan, en — indien nodig — zelf een officiële contactroute kiezen.

---

## Scenario’s A–D (kort)

| | |
|--|--|
| **A** | Fictief helpdesk/bankgesprek · eerst tonen · “Wat doet u nu?” · daarna pas STOP |
| **B** | Kort fictief helpdeskbericht (geen familie) |
| **C** | “Veilige rekening” · stop · niet overmaken |
| **D** | Eindmissie · nieuw scenario · 12 min · zonder voordoen |

---

## Officiële route

“Ik zoek zelf het officiële nummer via een route die ik al vertrouw.”  
App die u al gebruikt · eerder gecontroleerd officieel nummer · officiële site die u zelf opent.  
**Niet:** Contacten = veilig · nummer uit gesprek/bericht.

---

## Absoluut niet in de les

Echte bank bellen · software installeren · scherm delen · echte codes · betalingen · login verplicht · C4-familie/blokkeren · D4-betaalles.

---

## Vooraf (± 10–15 min)

1. Bekijk de beamer-PDF (volgorde scenario A: tonen → vraag → later antwoord).  
2. Lees Hulp bij vastlopen.  
3. Kaarten A–D + print + beamer + kabels.  
4. Helper kent: “Wat ziet u nu?” · Contacten ≠ veilig · niet ieder gesprek terugbellen.
