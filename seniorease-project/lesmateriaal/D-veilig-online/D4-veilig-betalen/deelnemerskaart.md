# Deelnemerskaart — D4 Veilig online betalen

Mee naar huis. Thuis binnen enkele seconden bruikbaar. Versie 2.0.

---

## Bij een betaalmoment

**VERWACHT**  
→ **CONTROLEER**  
→ **PAS DAN BEVESTIGEN**

### Ook

**STOP** → **NIET VERDERGAAN** → **ZELF CONTROLEREN**

### Vier vragen

1. Verwacht ik deze betaling?  
2. Ben ik zelf met deze aankoop begonnen?  
3. Klopt het bedrag?  
4. Past de ontvanger of betaalcontext bij wat ik wilde betalen?  

### Bij afwijking of twijfel

→ **NIET BEVESTIGEN** → **ZELF CONTROLEREN**

> “Nee, dit bevestig ik niet.”

### Doe dit niet

- NIET BETALEN bij twijfel  
- GEEN CODE DELEN  
- GEEN SOFTWARE INSTALLEREN  
- GEEN SCHERM DELEN  

### Let op

- Andere handelsnaam of betaalprovider is niet automatisch fraude — wel controleren.  
- Als de vier vragen “passen”, is dat geen bewijs dat een betaling veilig is.  
- Open zelf de route van uw eigen bank.

- [ ] Mijn bankroute zelf openen (zonder te moeten inloggen)  
- [ ] De vier vragen bij een betaalmoment gebruiken  
- [ ] Bij twijfel niet bevestigen  
- [ ] “Nee, dit bevestig ik niet” zeggen
