# C4 — Hulp bij vastlopen

**Voor begeleider en helper** · niet voor de beamer · Versie 2.0

---

## Centrale vraag

Eerst: **“Wat ziet u nu?”**

Daarna: vragen → uitleggen → aanwijzen → deelnemer doet zelf → pas als laatste kort overnemen.

Geen paniektaal. Geen volledige fraudeherstelprocedure.

---

## Situaties

### Ik weet niet of het bericht echt is
- U hoeft dat niet meteen zeker te weten.  
- **STOP** → zelf controleren via een contactgegeven dat u al had.

### De naam of foto lijkt bekend
- Profielfoto bewijst niet wie het is.  
- Toch controleren.

### Het is een nieuw nummer
- Extra reden om te stoppen.  
- Bel via een nummer dat u **al had**.  
- Niet meteen antwoorden.

### Er wordt om geld gevraagd
- Niet betalen.  
- Stop → zelf controleren.

### Er wordt om een code gevraagd
- Code **niet** doorgeven.

### Er staat een link in
- Niet tikken.  
- Eerst controleren.  
- Geen URL-analyse in deze les.

### Ik heb al geantwoord
- Stop **vanaf nu**.  
- Geen geld · geen code.  
- Zelf controleren.

### Ik heb al op een link getikt
- Geen paniektaal.  
- Niet verder invullen of bevestigen.  
- Sluit de pagina.  
- Individueel beoordelen welke vervolgstap nodig is.

### Ik kan blokkeren niet vinden
- “Wat ziet u nu?”  
- iPhone | Android.  
- Aanwijzen → deelnemer doet zelf.  
- Stop vóór bevestiging.

### Ik twijfel over rapporteren
- Blokkeren stopt contact.  
- Rapporteren bij vermoedelijke spam/fraude.  
- Niet verplicht bij elk ongewenst contact.  
- Rapporteren ≠ aangifte bij de politie.

### Mijn privacyinstellingen zien er anders uit
- “Dat is normaal.”  
- iPhone | Android.

### Ik weet niet welke privacykeuze ik moet maken
- Geen voorschrift.  
- U kiest zelf.  
- Helper helpt zoeken, niet beslissen.

### Ik heb een echt verdacht bericht
- Niet op de beamer.  
- Niet groepsgewijs analyseren.  
- Helper/begeleider individueel.  
- Niet klikken · niet verder reageren.  
- Bij ernstige gevolgen: passende officiële hulp / eigen organisatie.
