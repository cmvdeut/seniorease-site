## U hoeft geen fraude-expert te zijn

U begeleidt. Deelnemers oefenen op hun **eigen** telefoon.  
U hoeft **niet** te bewijzen: “Dit bericht is fraude.”  
U leert: bij twijfel kiezen we de veilige vervolgstap.

## Wat leert de deelnemer vandaag?

Na C4 weet de deelnemer wat te doen als een WhatsApp-bericht niet klopt en kan ongewenst contact stoppen.

**Hoofdkapstok:**  
STOP → NIET VERDERGAAN → ZELF CONTROLEREN  

**Concrete risico’s:**  
NIET BETALEN · GEEN CODE DELEN · NIET OP EEN ONVERWACHTE LINK TIKKEN  

## Vooraf controleren (± 10–15 min)

1. Bekijk de beamer-PDF.  
2. Controleer privacy-menu op **iPhone én Android**.  
3. Lees **C4 – Hulp bij vastlopen**.  
4. Klaarzetten: fictieve oefenberichten · blokkeer-/rapporteervoorbeeld (niemand echt blokkeren).  
5. Print · beamer · deelnemerskaarten · oplaadkabels.

## Oefenveiligheid (vast)

- Alleen **fictieve** SeniorEase-voorbeelden.  
- Geen echte nummers · codes · verdachte links · privégesprekken op beamer.  
- Blokkeren: route vinden · **stop vóór bevestiging**.  
- Echte casus van deelnemer: **niet** projecteren · helper 1-op-1.

## Belangrijke afspraken

- Bij vastlopen: eerst **“Wat ziet u nu?”**  
- Vragen → uitleggen → aanwijzen → zelf → pas laatste kort overnemen.  
- iPhone én Android **gelijkwaardig**.  
- “Uw scherm kan er iets anders uitzien. Dat is normaal.”  
- Eindmissie **niet** schrappen.  
- Geen Pakket D (QR · URL · DigiD · bankieren).

## Als iets anders loopt
