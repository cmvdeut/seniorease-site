## Klopt een WhatsApp-bericht niet?

**STOP**  
→ **NIET VERDERGAAN**  
→ **ZELF CONTROLEREN**

## Doe dit niet

**NIET BETALEN**  
**GEEN CODE DELEN**  
**NIET OP EEN ONVERWACHTE LINK TIKKEN**

## Extra reden om te stoppen

**GELD · CODE · HAAST · NIEUW NUMMER?**  
→ STOP EN CONTROLEER

## Zelf controleren

**BEL ZELF VIA EEN NUMMER DAT U AL HAD**

Niet via het nummer of de link uit het verdachte bericht.

→ indien passend: **RAPPORTEREN**
