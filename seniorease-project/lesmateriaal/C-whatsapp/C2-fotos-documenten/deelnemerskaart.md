# Deelnemerskaart — C2 Foto's en documenten via WhatsApp

**Pakket C** · telefoon of tablet · Versie 2.0  
Neem dit blad mee naar huis. Niet de hele les — alleen wat u nodig heeft.

---

## Kapstok

**ONTVANGEN → OPENEN → TERUGVINDEN → KIEZEN → CONTROLEREN → VERSTUREN**

---

## Foto ontvangen

**OPENEN → TERUG → TERUGVINDEN**

## Foto versturen

**KIEZEN → FOTO CONTROLEREN → PERSOON CONTROLEREN → VERSTUREN**

### Groot

**FOTO + PERSOON**  
→ DAN PAS VERSTUREN

---

## Document

**VERWACHT U DIT DOCUMENT?**  
→ DAN PAS OPENEN  

Bij twijfel:  
**NIET OPENEN** → EERST CONTROLEREN
