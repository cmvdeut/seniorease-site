# START HIER — voor de begeleider

**C2 · Foto's en documenten via WhatsApp** · Pakket C · Versie 2.0  
Ondertitel: Een foto of document ontvangen, terugvinden en veilig versturen  

Lees dit blad eerst. Daarna: draaiboek · beamer · hulpkaart.

---

## U hoeft geen technisch expert te zijn

U begeleidt. Deelnemers oefenen op hun **eigen** telefoon of tablet.  
U hoeft niet alle WhatsApp-knoppen of merken te kennen.

## Wat leert de deelnemer vandaag?

Na C2 kan de deelnemer een foto of document in WhatsApp openen en zelf een foto veilig naar de juiste persoon sturen.

**Route:** ONTVANGEN → OPENEN → TERUGVINDEN → KIEZEN → CONTROLEREN → VERSTUREN  

**Regels:**  
FOTO + PERSOON → dan pas versturen  
VERWACHT U DIT DOCUMENT? → dan pas openen  

## Vooraf (± 10–15 min)

1. Bekijk de beamer-PDF.  
2. Op uw telefoon kort: WhatsApp → oefencontact → oefenfoto sturen → oefendocument sturen.  
3. Lees **C2 – Hulp bij vastlopen**.  
4. Klaarzetten: print · beamer · deelnemerskaarten · oplaadkabels.  
5. Controleer oefenmateriaal (zie hieronder).

## Oefencontact (vast)

De organisatie zorgt voor een veilig WhatsApp-oefencontact: de **begeleider** of **helper**.  
Wie liever een **eigen** bekende kiest, mag dat ook.

- Controleer of het oefencontact herkenbaar is.  
- **Geen** telefoonnummers op de beamer.  
- **Geen** nummers door de zaal roepen.  
- Helper weet wanneer foto/document moet worden gestuurd.

## Oefenmateriaal klaarzetten

| Materiaal | Rol |
|-----------|-----|
| Lesfoto (neutraal object) | Tijdens de les ontvangen / versturen |
| Tweede eindmissiefoto | Deelnemer stuurt in de eindmissie |
| Neutrale retourfoto | Helper stuurt terug in de eindmissie |
| `SeniorEase-oefendocument-C2.pdf` | Tijdens de les |
| `SeniorEase-eindmissie-C2.pdf` | Alleen eindmissie |

**Helper zet vooraf klaar (eindmissie, 18 stappen):**  
tweede oefenfoto · neutrale retourfoto · `SeniorEase-eindmissie-C2.pdf`  
(Zie draaiboek — eindmissie. Binnen ca. 10–12 min uitvoerbaar houden.)

**Niet:** personen · kinderen · medische info · identiteitsdocumenten · privéfoto's als verplicht materiaal.

## Groep en helper

| | |
|--|--|
| **Maximaal** | ongeveer 8–10 deelnemers |
| **Helper** | sterk aanbevolen (1-op-1; gemengd iPhone/Android) |
| **Inloop** | vóór de les — telt **niet** mee in de 90 minuten |
| **Apparaat** | eigen telefoon of tablet met WhatsApp |

## Belangrijke afspraken

- Bij vastlopen: eerst **“Wat ziet u nu?”**  
- Daarna: vragen → uitleggen → aanwijzen → deelnemer zelf → pas als laatste kort overnemen.  
- iPhone én Android zijn **gelijkwaardig**.  
- “Uw scherm kan er iets anders uitzien. Dat is normaal.”  
- Eindmissie **niet** schrappen bij tijdgebrek — verkort liever herhalen.  
- **Niet** zeggen: “Een PDF is veilig.”  
- Geen bellen (C3) · geen fraude/privacy (C4).
