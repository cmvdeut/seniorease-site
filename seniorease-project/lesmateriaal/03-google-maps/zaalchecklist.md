# Zaalchecklist — Lesmiddag Google & Maps

## Ruimte en techniek

- [ ] Wifi werkt (8–10 telefoons)
- [ ] Wifi-wachtwoord op bord
- [ ] Stopcontacten / stekkerdozen
- [ ] Plaatsnaam van de les op het bord (voor zoekopdrachten)
- [ ] Beamer optioneel

## Printwerk

- [ ] 1× draaiboek
- [ ] 8–10× deelnemerskaart
- [ ] 8–10× oefentaken
- [ ] 8–10× nazorgkaart

## Mensen

- [ ] Begeleider 20 min voor start
- [ ] Helper 15 min voor start
- [ ] Max. 8–10 deelnemers
- [ ] Helper weet: Play Store / App Store voor Maps

## Na afloop

- [ ] Evaluatie 30 min
- [ ] Wifi-wachtwoord van het bord wissen
