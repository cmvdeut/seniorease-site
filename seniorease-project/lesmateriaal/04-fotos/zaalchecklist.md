# Zaalchecklist — Lesmiddag Foto’s

## Ruimte

- [ ] Genoeg licht (raamkant voor oefenen; geen fel tegenlicht)
- [ ] Stoelen met ruimte om telefoon vast te houden
- [ ] Beamer optioneel

## Techniek

- [ ] Wifi handig voor WhatsApp-delen, niet verplicht voor maken
- [ ] Stopcontacten / stekkerdozen
- [ ] Begeleider-telefoon klaar als oefenontvanger

## Printwerk

- [ ] 1× draaiboek
- [ ] 8–10× deelnemerskaart
- [ ] 8–10× oefentaken
- [ ] 8–10× nazorgkaart

## Mensen

- [ ] Begeleider 20 min voor start
- [ ] Helper 15 min voor start
- [ ] Max. 8–10 deelnemers
- [ ] Afspreken: geen foto’s van onbekenden zonder toestemming

## Na afloop

- [ ] Evaluatie 30 min
- [ ] Eventueel oefenfoto’s van deelnemers niet bewaren op begeleiders-telefoon zonder toestemming
