## Oneens / te vroeg

- “A–G sluiten aan, H ontbreekt” — onjuist: H = AI.
- Alles tegelijk (nieuw pakket + maandkaart + mantelzorg + campagnes).
- Appdwang/Wero als vast “grootste vraag” zonder eigen peiling.

## Gedaan op de site (deze ronde)

1. Blok **Waarom nu?** op `/lesmateriaal` (cijfers + bronnen voor coördinatoren).
2. **Herkenbare vraag** per themakaart A–H.
3. **Vertrouwensregel:** Digi-Hulplijn 0800 1508 + Informatiepunt Digitale Overheid (bibliotheek).
