## 3. Hoofdroute / kapstok (één praktische handelingsroute)

**OFFICIËLE ROUTE OPENEN → TAAK VINDEN → PERSOONLIJK DEEL HERKENNEN → NIETS AFRONDEN**

| Stap | Betekenis in E3 |
|------|-----------------|
| **OFFICIËLE ROUTE OPENEN** | Vooraf afgesproken officiële website van de vaste voorbeeldgemeente zelf openen |
| **TAAK VINDEN** | De afgesproken openbare taak vinden tot het startpunt |
| **PERSOONLIJK DEEL HERKENNEN** | Herkennen dat vanaf dit punt DigiD, persoonlijke gegevens, een formulier of een andere persoonlijke handeling nodig **kan** zijn · niet verplicht DigiD op iedere taak |
| **NIETS AFRONDEN** | Bewust stoppen vóór persoonlijke uitvoering · niets versturen / betalen / aanvragen |

Dit is de **enige** route die deelnemers leren. Geen tweede kapstok.

DigiD blijft waar relevant een herkenningsmoment (voortbouwend op E1) — geen vaste eis dat DigiD op iedere gemeentelijke taakroute verschijnt.

### Afsluiten versus uitloggen (pakketregel · exact)

| Situatie | Handeling |
|----------|-----------|
| **Niet ingelogd** | → tabblad/app **sluiten** |
| **Wel ingelogd** | → eerst **uitloggen** → daarna eventueel tabblad/app sluiten |

“Uitloggen” nooit vragen wanneer iemand niet is ingelogd.  
Standaard groepsroute: **sluiten**.

### B. Begeleide oefentaak (voorstel · taak A)

| | |
|--|--|
| **Taak** | **Verhuizing doorgeven** |

> U heeft gevonden waar u moet zijn. Hier stopt de oefening.

### C. Eindmissietaak (voorstel · taak B)

| | |
|--|--|
| **Taak** | **Paspoort / identiteitskaart — informatie of afspraakroute vinden** *(exacte label bij productie afstemmen op actuele navigatie)* |
| **Doel** | Andere openbare taak op **dezelfde** voorbeeldgemeente zelf vinden · stoppen vóór persoonlijke gegevens / DigiD-login / versturen |
| **Waarom** | Vergelijkbare omgeving · andere navigatiepad → test **transfer**, niet alleen geheugen · geen betaling nodig om startpunt te vinden |

**Als bij live-controle taak B ongeschikt blijkt:** kies een andere openbare, neutrale taak op dezelfde site (bijv. afspraak maken · melding openbare ruimte · openingstijden Stadskantoor), mits:

- openbaar vindbaar  
- veilig  
- geen echte login nodig om startpunt te vinden  
- geen betaling  
- geen persoonlijke invoer nodig voor de missie  
- duidelijk verschillend van taak A  

### Alternatief als Utrecht bij verificatie faalt

Kies een andere Nederlandse gemeente met dezelfde criteria.  
Houd één vaste gemeente voor de hele groep.  
Wijzig **niet** zelfstandig de leerdoelen.

## 7. Officiële route openen (kernhandeling)

Deelnemer opent zelf de afgesproken officiële route van de voorbeeldgemeente.

**Zegt (richting):** “We openen de officiële website van de voorbeeldgemeente zelf.”  
Exact adres: pas na verificatie vastzetten.

**Niet:**

- Google zoeken als les  
- advertenties / zoekresultaten vergelijken  
- domeinen ontleden · URL-veiligheid · tabbladen · favorieten  

Korte D-brug (één zin, geen phishingles):

> Gebruik de officiële route die voor deze oefening is afgesproken.

Telefoon/tablet én computer gelijkwaardig.  
iPhone én Android gelijkwaardig.

> “Uw scherm kan er iets anders uitzien. Dat is normaal.”

## 8. Een taak vinden (nieuwe kernvaardigheid)

Op de gekozen overheidssite:

- herkennen waar inwonerszaken / diensten ongeveer staan  
- de afgesproken taak vinden  
- herkennen waar verdere actie begint  
- stoppen vóór persoonlijke uitvoering  

Gebruik de **werkelijke** navigatie van de voorbeeldgemeente.  
Geen kunstmatige “universele gemeente-structuur”.

---

## 9. Persoonlijk deel herkennen

**PERSOONLIJK DEEL HERKENNEN** betekent:

herkennen dat vanaf dit punt bijvoorbeeld DigiD, persoonlijke gegevens, een formulier of een andere persoonlijke handeling nodig **kan** zijn.

Het betekent **niet** dat DigiD altijd op iedere gemeentelijke taakroute moet verschijnen.

Wanneer DigiD of persoonlijke invoer zichtbaar is:

> Hier begint het persoonlijke deel.

Bouw voort op E1. Geen nieuwe DigiD-les. Geen echte login.

Nooit klassikaal:

- begeleidersaccount  
- wachtwoord · code · BSN · persoonlijke gegevens  

**Begeleider:**

> Hier zou u thuis verder kunnen gaan. In de les stoppen we vóór persoonlijke gegevens.

|--|--|

## 12. Belastingdienst (korte transfer · geen tweede hoofdroute)

Architectuur noemt gemeente én Belastingdienst.  
In E3-inhoud v2.0:

- **Gemeente (vaste voorbeeldgemeente)** = hoofdroute  
- **Belastingdienst** = korte transfer / herkenning (blok 70–78)  

Doel van de transfer:

> Ook hier zoekt u eerst de officiële route en waar u moet beginnen.

| Wel | Niet |
|-----|------|
| `belastingdienst.nl` openen (exacte URL bij productie verifiëren) | Belastingaangifte |
| Inloggen / Mijn Belastingdienst herkennen | Toeslagen · bedragen · betalen |
| Stoppen vóór persoonlijke stappen | Echte login · persoonlijke belastinggegevens |

**Bij uitloop:** transfer inkorten tot één zin op deelnemerskaart / START HIER.  
Geen tweede volledige oefenroute.

## 17. Eindmissie

**Bescherm exact 12 minuten.** Geen voordoen. Geen antwoordstappen op deelnemersbeamer.

### Open opdracht (deelnemersbeamer · richting)

> U wilt iets anders regelen bij dezelfde voorbeeldgemeente.  
> Laat zien waar u zelf begint en vind waar u deze taak kunt regelen.  
> Stop voordat u persoonlijke gegevens invult of iets verstuurt.

*(Exacte taak B-label na verificatie invullen — voorstel: paspoort / identiteitskaart-route.)*

### Wat de deelnemer zelfstandig laat zien

- Officiële voorbeeldgemeente-route zelf openen  
- Nieuwe openbare taak (B) vinden  
- Persoonlijk deel herkennen (waar relevant)  
- Niets persoonlijks invullen · niets versturen · niets betalen  
- Weten wanneer te stoppen  
- Correct afsluiten: **sluiten** (standaard)  

### Mag niet mislukken omdat

- deelnemer geen DigiD heeft  
- deelnemer niet wil inloggen  
- deelnemer geen echte aanvraag wil doen  
- deelnemer in een andere gemeente woont  

### Observatiechecklist begeleider (niet op beamer)

1. Opent zelf de afgesproken officiële route.  
2. Vindt de nieuwe openbare taak (B) — niet alleen taak A uit geheugen.  
3. Herkent het persoonlijke deel (DigiD / gegevens / formulier — waar de route dat toont).  
4. Vult geen wachtwoord/code/BSN/persoonsgegevens in · noemt niets hardop.  
5. Verstuurt / bevestigt / betaalt niets.  
6. Stopt bewust op het afgesproken type stoppunt.  
7. Sluit tabblad/app af (niet “uitloggen” tenzij optioneel echt was ingelogd).  
8. Geen persoonlijke gegevens klassikaal · geen inhoudelijk advies over de regeling.

**Afsluiting (richting):**

> Gelukt? Dan kunt u zelf een officiële overheidsroute openen, een taak vinden en herkennen waar u moet beginnen — zonder iets af te ronden. Volgende keer: berichten van de overheid vinden en lezen.

## 18. Hulp bij vastlopen (inhoud)

Centrale vraag: **“Wat ziet u nu?”**  
Volgorde: vragen → uitleggen → aanwijzen → deelnemer zelf → pas laatste kort overnemen.

| Situatie | Hulp |
|----------|------|
| Ik weet niet waar ik moet beginnen | Gebruik de afgesproken officiële route · helper 1-op-1 · geen Google-les |
| De website opent niet | Wifi · opnieuw typen · helper 1-op-1 · groep niet stilleggen |
| Mijn scherm ziet er anders uit | Dat is normaal |
| Ik zie de afgesproken taak niet | Helper 1-op-1 · “Wat ziet u nu?” · wijst daarna kort aan |
| Ik kom op een andere pagina | Terug naar de afgesproken start · opnieuw zoeken binnen de site |
| Ik zie een zoekvak op de gemeentewebsite | Mag · zoek de afgesproken taaknaam · geen algemene zoekles |
| Ik zie Inloggen | Kijken / herkennen · niet invullen |
| Ik zie DigiD | Hier begint het persoonlijke deel · stop in de les |
| Er wordt om persoonlijke informatie gevraagd | Stop · vul niets in · oefening is klaar |
| Er wordt om mijn BSN gevraagd | Stop · vul niets in · nooit hardop |
| Er wordt om een betaling gevraagd | Stop · niet betalen · verkeerde diepte of andere taak |
| Moet ik nu verder? | Nee — u heeft gevonden waar u moet zijn · hier stopt de oefening |
| Ik wil de taak echt uitvoeren | Niet in de les · thuis / IDO / gemeente / organisatie |
| Mijn eigen gemeente ziet er anders uit | Dat is normaal · oefenvoorbeeld is de groepsroute |
| Ik wil dezelfde taak bij mijn eigen gemeente vinden | OPTIONEEL · 1-op-1 met helper · groep wacht niet · geen echte aanvraag |
| Ik heb geen DigiD | Prima · les lukt zonder DigiD |
| Mijn DigiD werkt niet | Niet klassikaal · doorverwijzen |
| Ik heb een inhoudelijke vraag over de regeling | Niet gokken · officiële organisatie / IDO / Digisterker / bibliotheek / organisatie |

Geen paniektaal. Geen schaamte.  
Begeleider is **geen** expert op gemeentelijke regelingen.
