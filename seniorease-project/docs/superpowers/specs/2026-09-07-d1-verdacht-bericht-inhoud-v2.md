D1 **opent** Pakket D.

**Centrale vraag:**

> Wat doe ik als een bericht onverwacht om actie vraagt — en hoe controleer ik **zelf**?

**Aansluiting C4 (zonder herhaling):**

- C4 oefende dit **in WhatsApp**: nieuw nummer · geld · code · link · blokkeren · privacy.

- Geen WhatsApp-blokkeren, geen privacy-instellingen, geen familie/nieuw-nummer-hoofdscenario.

## 2. Centrale situatie

> “U krijgt een bericht dat er iets mis is met uw account. U moet snel op een link tikken. Wat doet u?”

**Beamer (opening):**

- U krijgt een bericht: er zou iets mis zijn met uw account.  
- U moet snel op een link tikken.  
- Wat doet u?

Niet openen met: “Vandaag behandelen we phishing en nepberichten.”

### Fictief oefenbericht A — account (hoofdscenario)

> **Oefening SeniorEase — geen echt bericht.**  
> Er is een probleem met uw account.  
> Binnen 1 uur geblokkeerd.  
> Tik hier om te herstellen.  
> *(Geen echte link. Geen echt telefoonnummer.)*

### Fictief oefenbericht B — tweede situatie (herhaling)

> **Oefening SeniorEase — geen echt bericht.**  
> Uw pakket wacht.  
> Bevestig vandaag nog — anders retour.  
> Open de link in dit bericht.  
> *(Geen echte link.)*

### Fictief oefenbericht C — eindmissie (nieuw)

> **Oefening SeniorEase — geen echt bericht.**  
> Belangrijk: er is activiteit op uw account.  
> Log nu in via deze melding.  
> Dit moet binnen 10 minuten.  
> *(Geen echte link. Geen echte code.)*

**Belangrijk:** de les gaat **niet** onderzoeken of het bericht “er echt uitziet”.  
De les leert **gedrag:** STOP · niet verdergaan · zelf controleren.

### Fictieve kaart versus echt toestel (vast)

- Berichten **A / B / C** zijn **kijkvoorbeelden** (beamer of printkaart).  
- Er worden **geen** frauduleuze oefen-sms’jes of WhatsApp-berichten naar deelnemers gestuurd.  
- Geen klikbare verdachte links.  
- De begeleider demonstreert “terug / verlaten” op een **veilig demonstratiescherm** (eigen toestel of neutrale demo) — **niet** alsof de beamerkaart op de telefoon van de deelnemer staat.  
- Deelnemers oefenen de terughandeling op hun **eigen toestel** vanuit een **neutrale veilige situatie** (bijv. startscherm of Berichten-app zonder verdacht oefenbericht).  
- Instructies zeggen nooit: “Open dit bericht op uw telefoon” over een beamerkaart.

## 3. Gouden kapstokken

| Kapstok | Betekenis |
|---------|-----------|
| **STOP → NIET VERDERGAAN → ZELF CONTROLEREN** | Hoofdkapstok Pakket D / D1 |
| **NIET BETALEN · GEEN CODE DELEN · NIET OP EEN ONVERWACHTE LINK TIKKEN** | Concrete risico’s |
| **ONVERWACHT VERZOEK? → STOP → ZELF CONTROLEREN** | Leskapstok D1 |
| **CONTROLEREN VIA EEN OFFICIËLE ROUTE DIE U ZELF KIEST** | Wat “zelf controleren” betekent |
| **Passende dienst** | Accountbericht → route van die dienst · pakketbericht → route van die vervoerder |

**Vaste formulering (controleroute):**

> Ik open zelf de officiële route van de dienst waarover het bericht gaat en controleer daar of er werkelijk iets aan de hand is.

Beamer: niet alles tegelijk. Kapstokken één voor één, gekoppeld aan de fase.

### Vijf vragen — begeleidershulpmiddel

**Niet** vijf regels die deelnemers uit het hoofd moeten leren.  
Wel: begeleider/helper gebruikt ze om het gesprek te sturen.

1. Verwachtte ik dit?  
2. Wat wordt er gevraagd?  
3. Moet het snel?  
4. Via welke route moet ik handelen?  
5. Hoe kan ik zelf controleren?

## 4. Leerdoelen — na D1 zelfstandig kunnen

1. Een onverwacht verzoek herkennen als reden om te stoppen  
2. Niet via het bericht verder handelen (geen link · geen betaling · geen code)  
3. Begrijpen dat naam, logo of foutloze tekst **geen** bewijs is  
4. Het bericht verlaten / wegleggen  
5. Zelfstandig de **passende** officiële route openen van de dienst waarover het bericht gaat  
6. Bij twijfel niet verdergaan  
7. Onderscheid begrijpen tussen **navigatie oefenen** en **het verzoek controleren** 

### Expliciet buiten D1

Geen:

- technische URL-analyse / domeinles → **D2**  
- QR-codes → **D2**

- betaalcontrole / iDEAL → **D4**  
- WhatsApp blokkeren / rapporteren / privacy → **C4**  
- familie / nieuw-nummer als hoofdscenario → **C4**  
- echte banklogin  
- echte verdachte berichten klassikaal analyseren

## 6. Oefenroute A versus controleroute B (vast)

Maak altijd onderscheid:

| | A — Veilig oefenen (navigatie) | B — Daadwerkelijk controleren |
|--|-------------------------------|-------------------------------|
| **Doel** | Zelfstandig navigeren oefenen: stoppen · verlaten · zelf ergens heen | Het **oorspronkelijke verzoek** controleren via de passende officiële dienst |
| **Voorbeeld** | SeniorEase-veiligheidspagina (`seniorease.nl/uitleg/veiligheid`) — mits die pagina bestaat | Accountbericht → DigiD / betreffende dienst · Pakketbericht → PostNL / betreffende vervoerder |
| **Claim** | “We hebben de **veilige controleroute** geoefend.” | “Ik open zelf de officiële route van de dienst waarover het bericht gaat en controleer daar of er werkelijk iets aan de hand is.” |
| **Niet claimen** | Dat het fictieve account-/pakketprobleem **werkelijk** is gecontroleerd | — |

**Geen** verplichte login. **Geen** echte accountgegevens. **Geen** echte verdachte links.

Een **willekeurige** vertrouwde app openen is **niet voldoende** om het oorspronkelijke bericht als gecontroleerd te beschouwen.

### A — Neutrale navigatieoefening (groep)

1. Fictief bericht **alleen bekijken** op beamer/printkaart (geen klikbare link · staat niet op de deelnemerstelefoon).  
2. **STOP** — niet tikken.  
3. Begeleider toont “terug/verlaten” op **veilig demonstratiescherm**.  
4. Deelnemers oefenen op eigen toestel vanuit **neutrale veilige situatie** (startscherm / Berichten zonder oefen-fraudebericht): terug naar start · browser of app openen.  
5. Open de **SeniorEase-veiligheidspagina** door zelf te typen:  
   `seniorease.nl/uitleg/veiligheid`  
   *(vóór productie exact controleren dat deze URL live is — geen placeholder.)*  
6. Zeg duidelijk: dit is de **navigatieoefening** — niet de controle van het fictieve accountprobleem.

### B — Passende controleroute (bij het type bericht)

| Berichttype | Passende route (zonder verplicht inloggen) |
|-------------|--------------------------------------------|
| Accountbericht (A / C) | Officiële route van de **betreffende dienst** (bijv. DigiD-app of digid.nl tot herkenbaar startscherm) |
| Pakketbericht (B) | Officiële route van de **betreffende vervoerder** (bijv. PostNL-app of postnl.nl) |

**Zegt u:**

> Ik open zelf de officiële route van de dienst waarover het bericht gaat en controleer daar of er werkelijk iets aan de hand is.

In de les: openen/herkennen mag; **inloggen en accountgegevens zijn niet verplicht en niet gevraagd**.

### 2–3 herkenbare voorbeelden (beamer — ondersteunend bij B)

1. DigiD-app of digid.nl *(herkennen — niet inloggen)*  
2. PostNL-app of postnl.nl  
3. Eventueel een derde bestaande overheids-/dienstroute op SeniorEase  

**Niet:** “Kies maar een willekeurige app die u vertrouwt” als vervanging voor B.

## 8. Tijdlijn (~90 minuten)

Inloop valt **buiten** de 90 minuten.

| Tijd | Onderdeel |
|------|-----------|
| 0–5 | Welkom + centrale situatie |
| 5–12 | Kapstok STOP → NIET VERDERGAAN → ZELF CONTROLEREN |
| 12–25 | Bericht A alleen kijken (kijkvoorbeeld) + vijf vragen |
| 25–40 | Navigatieoefening A (SeniorEase-veiligheidspagina) |
| 40–50 | Controleroute B — passende dienst bij accountbericht |
| 50–55 | Pauze |
| 55–70 | Tweede situatie (bericht B) — controleroute vervoerder |
| 70–78 | Herhalen / hulp bij vastlopen |
| 78–90 | Eindmissie (**12 min** · bericht C · open opdracht · zonder voordoen) |

**Bij uitloop:** blok 40–50 en/of tweede situatie inkorten.  
**Nooit:** eindmissie schrappen.

Methode in begeleidersdocs: **ZIEN → NADOEN → BEGRIJPEN → ZELF DOEN**.

#### Observatiechecklist begeleider/helper (niet op deelnemersbeamer)

De zeven stappen blijven als **observatiechecklist**:

1. Leest het fictieve bericht.  
2. Benoemt waarom hij/zij stopt (onverwacht · haast · link · account).  
3. Gaat **niet** via het bericht verder (geen link · geen code · geen betaling).  
4. “Verlaat” het verzoek (legt het kijkvoorbeeld weg / stopt ermee).  
5. Kiest de **passende** officiële route van de dienst waarover het bericht gaat.  
6. Legt uit wat daar gecontroleerd zou worden (zonder verplicht inloggen).  
7. Maakt duidelijk: niet via het bericht gehandeld.

**Deelnemer beslist zelfstandig** — begeleider observeert met de checklist.

**Afsluiting (exact):**

> Gelukt? Dan weet u wat u veilig kunt doen als een bericht onverwacht om actie vraagt: stoppen, niet verdergaan via het bericht, en zelf de officiële route van de juiste dienst kiezen.

## 10. Hulp bij vastlopen (inhoud)

Centrale vraag: **“Wat ziet u nu?”**  
Volgorde: vragen → uitleggen → aanwijzen → zelf → pas laatste kort overnemen.

| Situatie | Hulp |
|----------|------|
| Ik weet niet of het bericht echt is | U hoeft dat niet te bewijzen. STOP · zelf controleren |
| Er staat een bekende naam of logo | Dat bewijst niet wie het is. Toch stoppen |
| Er staat een link in | Niet tikken · wegleggen · passende officiële route |
| Er wordt om haast / account gevraagd | Extra reden om te STOPPEN |
| Ik heb al op iets getikt | Stop vanaf nu · niet verder invullen · helper 1-op-1 |
| Ik vind Berichten / browser niet | iPhone \| Android tonen · “Uw scherm kan anders zijn” |
| Staat dit bericht op mijn telefoon? | Nee — dit is een kijkvoorbeeld op de beamer/kaart |
| Mag ik zomaar een andere app openen? | Voor navigatieoefening A: SeniorEase-pagina. Voor controle B: de **passende** dienst |
| Ik wil DigiD/bank openen | Mag als passende controleroute — **niet** inloggen in de les |
| Heb ik het probleem echt gecontroleerd? | Bij alleen navigatieoefening: nee — u heeft de **veilige controleroute** geoefend |
| Mijn scherm ziet er anders uit | Dat is normaal |
| Ik heb een echt verdacht bericht | Niet op beamer · helper 1-op-1 · niet klikken · bij ernst: officiële hulp / organisatie |
| Ik wil weten of spelfouten fraude zijn | Spelfouten bewijzen niets · focus op stoppen en zelf controleren |

Geen paniektaal. Geen volledige fraudeherstelprocedure.

- stoppen bij een onverwacht bericht
