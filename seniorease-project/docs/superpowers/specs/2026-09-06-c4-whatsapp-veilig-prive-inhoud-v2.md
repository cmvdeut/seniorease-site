## 1. Titel & belofte

**Titel:** C4 — Veilig en privé WhatsApp gebruiken  

**Ondertitel:** Verdachte berichten herkennen, controleren en ongewenst contact stoppen  

**Kernbelofte:**

> Ik weet wat ik moet doen als een WhatsApp-bericht niet klopt en kan ongewenst contact blokkeren.

Privacy-instellingen zijn belangrijk, maar **niet** de hoofdzin van de kernbelofte.

---

## 2. Centrale situatie

> “U krijgt via WhatsApp een bericht van iemand die zegt dat hij een bekende is en dringend hulp nodig heeft. Wat doet u?”

**Beamer (opening):**

- U krijgt via WhatsApp een bericht van iemand die zegt dat hij een bekende is.  
- Hij zegt dat hij dringend hulp nodig heeft.  
- Wat doet u?

Niet: “Vandaag behandelen we WhatsApp-fraude en privacy-instellingen.”

### Fictief oefenbericht (hoofdscenario)

> Hoi mam, dit is mijn nieuwe nummer.  
> Mijn telefoon is kapot.  
> Kun je me even helpen?

Later in het fictieve gesprek:

> Kun je €350 voor me betalen?  
> Ik betaal het vanavond terug.

**Belangrijk:** de les gaat **niet** onderzoeken of het bericht “er echt uitziet”.

De les leert **gedrag:**

- STOP.  
- Niet verdergaan.  
- **NIET BETALEN · GEEN CODE DELEN · NIET OP EEN ONVERWACHTE LINK TIKKEN**  
- Zelf controleren via een contactgegeven dat u **al had**.

*(In het nieuw-nummer-scenario mag specifiek “niet meteen antwoorden” blijven staan.)*

## 3. Gouden kapstokken

| Kapstok | Betekenis |
|---------|-----------|
| **STOP → NIET VERDERGAAN → ZELF CONTROLEREN** | Hoofdkapstok van C4 |
| **NIET BETALEN · GEEN CODE DELEN · NIET OP EEN ONVERWACHTE LINK TIKKEN** | Concrete risico’s — niet “nooit iets doen” |
| **GELD · CODE · HAAST · NIEUW NUMMER? → STOP EN CONTROLEER** | Waarschuwingsmoment |
| **GEBRUIK EEN NUMMER DAT U ZELF AL HAD** | Controle buiten het verdachte gesprek |
| **NIET VERDER → BLOKKEREN → EVENTUEEL RAPPORTEREN** | Ongewenst contact |
| **DEEL ALLEEN WAT U WILT DELEN** | Privacy als keuze |

Beamer: **niet alles tegelijk** op één dia. Kapstokken één voor één, gekoppeld aan de fase.

### Controle — kernvoorbeeld

Uw zoon zegt via een **nieuw nummer** dat hij geld nodig heeft.

**Niet:** het nieuwe nummer bellen om te vragen of hij het echt is.  
**Wel:** het **oude, bekende** nummer van uw zoon zelf bellen — of op een andere vertrouwde manier contact opnemen die u al kende.

## 4. Belangrijke nuance (vast)

**Geen** simplistische kenmerken zoals:

- spelfout = fraude  
- buitenlands nummer = fraude  
- profielfoto ontbreekt = fraude  
- onbekend nummer = altijd fraude  
- goed geschreven bericht = betrouwbaar  
- bekende profielfoto = veilig  

**Wel duidelijk maken:**

> Een bericht kan er heel echt uitzien.

Daarom is de belangrijkste vaardigheid **niet**:

“Kan ik zien of dit nep is?”

maar:

“Wat doe ik als iets niet klopt of onverwacht is?”

**Gewenst gevoel:**

> Ik hoef niet zeker te weten of het nep is.  
> Ik weet wat ik veilig kan doen.

Gebruik liever **“Wat doet u nu?”** dan **“Is dit bericht echt of nep?”**

### Blokkeren — standaardwerkvorm

Deelnemers blokkeren **niet** hun echte familie/vrienden.  
Er wordt tijdens de standaardles **niemand daadwerkelijk geblokkeerd**.

**Standaardwerkvorm:**

1. Fictief / geanonimiseerd voorbeeld op de **beamer**.  
2. Deelnemer volgt waar praktisch mogelijk op de eigen telefoon de route bij het **afgesproken veilige oefencontact**.  
3. Deelnemer vindt **Blokkeren**.  
4. Deelnemer **stopt vóór de definitieve bevestiging**.

**Kernvaardigheid:**

> Ik kan vinden waar ik ongewenst contact kan blokkeren en begrijp wat blokkeren doet.

Eindmissie blijft: “Wijs aan waar u dit ongewenste contact zou blokkeren.”

## 7. START HIER — C4 (vast)

Begeleider hoeft **geen fraude-expert** te zijn.

De begeleider hoeft **niet** te bewijzen: “Dit bericht is fraude.”  
De begeleider leert deelnemers: “Bij twijfel kiezen we de veilige vervolgstap.”

### Voorbereiding

- Fictieve screenshots klaar  
- Fictief blokkeer-/rapporteervoorbeeld klaar (niemand daadwerkelijk blokkeren)  
- WhatsApp privacy-menu vooraf controleren op **iPhone + Android**  
- Geen echte privégesprekken gebruiken  
- Helper kent hoofdregel: **STOP → NIET VERDERGAAN → ZELF CONTROLEREN**  
- Helper kent concrete risico’s: **NIET BETALEN · GEEN CODE DELEN · NIET OP EEN ONVERWACHTE LINK TIKKEN**  
- Begeleider weet wat te doen als iemand met een **echte casus** komt (zie §12 / §22)

## 8. Leerdoelen — na C4 zelfstandig kunnen

1. Bij een vreemd/onverwacht WhatsApp-bericht **stoppen** (niet verdergaan)  
2. Signalen herkennen als **reden om te stoppen**: geld · code · haast · nieuw nummer (niet als “bewijs van fraude”)  
3. Bij concrete risico’s: **niet betalen · geen code delen · niet op een onverwachte link tikken**  
4. **Zelf controleren** via een contactgegeven dat u **al had** (niet via nummer/link uit het verdachte bericht)  
5. Bij onverwachte link: **niet tikken** (klein — geen linkles)  
6. Waar **Blokkeren** vinden + begrijpen wat blokkeren doet (in de standaardles **niet** daadwerkelijk bevestigen)  
7. **Rapporteren** als kleinere stap: verschil met blokkeren · wanneer passend  
8. Weten dat u in WhatsApp **zelf kiest** wie bepaalde informatie kan zien  
9. Drie privacyplekken vinden: **profielfoto** · **laatst gezien / online** · **wie u aan groepen kan toevoegen**  
10. Kort meenemen uit C3: in een **groep** kunnen meerdere mensen lezen wat u deelt  

*(Nieuw-nummer-scenario: “niet meteen antwoorden” blijft daar een concrete stap.)*

## 11. Doorlopende oefensituatie (vast)

Eén hoofdverhaal — **geen** reeks losse quizvragen.

### Fase 1 — Nieuw nummer (hoofdscenario)

Fictief bericht:

> Hoi mam, dit is mijn nieuwe nummer.  
> Mijn telefoon is kapot.  
> Kun je me even helpen?

Vraag: **“Wat doet u nu?”** — niet: “Is dit fraude?”

Gewenst gedrag:

1. STOP.  
2. Niet meteen antwoorden.  
3. Niet aannemen dat de profielfoto bewijst wie het is.  
4. Open zelf het bekende contact / gebruik het nummer dat u al had.  
5. Bel de persoon zelf (of andere vertrouwde route die u al kende).  
6. Controleer **buiten** het verdachte gesprek.

Kern: **ZELF CONTROLEREN** via contactgegevens die u al had.

### Fase 2 — Geld + haast

Vervolg fictief:

> Kun je €350 voorschieten?  
> Het moet nu betaald worden.  
> Ik betaal het vanavond terug.

Deelnemers signaleren: **geld** · **haast** · **onverwacht verzoek**.

**Niet:** “Geld vragen via WhatsApp is altijd fraude.”  
**Wel:** Geld + onverwacht + haast = reden om te **STOPPEN** en zelf te controleren.

Geen echte betaling · geen betaalapp · geen QR · geen bankwebsite · geen betaalverzoek oefenen → **Pakket D**.

### Fase 3 — Code (+ link klein)

Kort apart fictief voorbeeld:

> Ik heb per ongeluk een code naar jouw telefoon laten sturen.  
> Kun je die even doorgeven?

**Eenvoudige regel:**

> Krijgt u een code op uw telefoon?  
> Geef die niet door omdat iemand er in WhatsApp om vraagt.

**Link — alleen klein:**

> Onverwachte link? → Niet tikken → Eerst controleren.

Geen URL-analyse · geen domeinnamen · geen browsercontrole · geen QR.

### Fase 4 — Contact stoppen

Wat als het contact blijft doorgaan?

→ **Blokkeren**  
→ **Rapporteren** indien passend  

**Blokkeren (kernvaardigheid):**

> Ik kan vinden waar ik ongewenst contact kan blokkeren en begrijp wat blokkeren doet.

Standaardles:

- Fictief/geanonimiseerd voorbeeld op beamer  
- Route op eigen telefoon bij veilig oefencontact (waar praktisch mogelijk)  
- Blokkeren vinden  
- **Stoppen vóór definitieve bevestiging** — niemand daadwerkelijk blokkeren  

Eenvoudige uitleg:

> Als u iemand blokkeert, kan die persoon u via WhatsApp niet meer op de gewone manier berichten of bellen.

*(Bij bouw: actuele WhatsApp-tekst/interface controleren — niet nu op details vastlopen.)*

**Rapporteren (kleiner):**

| | |
|--|--|
| **Blokkeren** | U stopt het contact met deze persoon. |
| **Rapporteren** | U meldt het contact/gesprek bij WhatsApp. |

- Niet ieder ongewenst persoonlijk contact hoeft gerapporteerd.  
- Bij vermoedelijke spam/fraude kan rapporteren passend zijn.  
- Route: **BLOKKEREN → indien passend: RAPPORTEREN**  
- Niet suggereren dat rapporteren = politie/aangifte.  
- Geen uitgebreide moderatie-uitleg.

### Fase 5 — Privacy (compact)

Nu kijken we kort wat anderen van **ú** in WhatsApp kunnen zien.

**Maximaal drie onderwerpen:**

1. Profielfoto  
2. Laatst gezien / online  
3. Wie u aan groepen kan toevoegen  

**Privacy = keuze** — SeniorEase schrijft **niet** voor: “Iedereen moet profielfoto op Niemand zetten.”

> U kiest zelf wie uw profielfoto mag zien.

Opties tonen zoals WhatsApp ze **op het moment van bouwen** echt noemt.

**Groepen (aansluiting C3, klein):**

C3: KIJK BOVENAAN — één persoon of groep?

> Staat u in een groep?  
> Bedenk dan dat meerdere mensen kunnen lezen wat u daar deelt.

Plus: “U kunt beperken wie u zomaar aan een WhatsApp-groep kan toevoegen.”  
Geen groepsles · geen groep maken · geen groepsbeheer.

### Logische route van de les

VREEMD BERICHT → STOP → CONTROLEREN → CONTACT STOPPEN → PRIVACY BEHEREN

## 12. Veiligheid van de oefening (vast)

**Nooit:**

- echt geld overmaken  
- echte code delen  
- echte verdachte link openen  
- echte fraudeur contacteren  
- echt onbekend nummer bellen  
- privégesprekken op beamer  
- persoonlijke beveiligingsinstellingen hardop delen  
- deelnemer verplichten privacyinstelling te veranderen  

**Als een deelnemer een echt verdacht bericht toont:**

- **Niet** op de beamer zetten  
- **Niet** met de hele groep analyseren  
- Begeleider/helper kijkt **individueel** mee  
- Niet klikken / niet reageren  
- Bij financiële of andere serieuze gevolgen: verwijzen naar passende **officiële** hulp/organisatie  

C4 is **educatie**, geen individuele fraude-afhandeling.

## 14. Eindmissie · zonder voordoen · altijd behouden

Geen voordoen.  
**Nieuw** fictief voorbeeld — niet exact hetzelfde “nieuwe nummer”-bericht uit de les.

**Fictief eindmissie-bericht:**

> Hallo, ik help u met uw account.  
> Er is iets mis.  
> Stuur mij de code die u zojuist heeft ontvangen.  
> Dit moet binnen 10 minuten.

Geen echte organisatie-/banknaam gebruiken.

**Beamer:** Kunt u dit zelf?

1. Lees het fictieve WhatsApp-bericht.  
2. Benoem wat u laat stoppen (bijv. code / haast / onverwacht contact).  
3. Reageer niet op het bericht.  
4. Geef geen code door.  
5. Leg uit hoe u zelf zou controleren.  
6. Gebruik daarvoor **geen** contactgegeven uit het verdachte bericht.  
7. Wijs aan waar u dit ongewenste contact zou **blokkeren**.  
8. Leg kort uit wanneer **rapporteren** passend kan zijn.  
9. Ga naar de **privacy-instellingen** van WhatsApp.  
10. Zoek waar u kunt kiezen wie uw **profielfoto** mag zien.

Stap 9–10: **niet verplicht** de privacywaarde daadwerkelijk wijzigen. Doel: zelf de juiste plek vinden en begrijpen dat dit een **keuze** is.

**Afsluiting (exact):**

> Gelukt? Dan weet u wat u veilig kunt doen als een WhatsApp-bericht niet klopt en waar u uw privacy kunt regelen.

## 15. Hulp bij vastlopen (kernpunten)

| Situatie | Richting |
|----------|----------|
| Ik weet niet of het bericht echt is | U hoeft dat niet meteen zeker te weten → **STOP** → zelf controleren via contactgegeven dat u al had |
| Ik herken de naam / profielfoto | Profielfoto bewijst niet wie het is → toch controleren |
| Het bericht komt van een nieuw nummer | Extra reden om te stoppen → bel via nummer dat u **al had** |
| Er wordt om geld gevraagd | Niet betalen → stop → zelf controleren |
| Er wordt om een code gevraagd | Code **niet** doorgeven |
| Er staat een link in | Niet tikken → eerst controleren (klein) |
| Ik heb al gereageerd | Stop **vanaf nu** · geen geld/code · zelf controleren |
| Ik heb al op de link getikt | Geen paniektaal · niet verder invullen/bevestigen · sluit de pagina · individueel beoordelen welke vervolgstap nodig is |
| Ik kan Blokkeren niet vinden | “Wat ziet u nu?” · iPhone \| Android · aanwijzen · zelf |
| Ik weet niet of ik moet rapporteren | Blokkeren stopt contact · rapporteren bij vermoedelijke spam/fraude · niet verplicht bij elk ongewenst contact |
| Mijn privacy-menu ziet er anders uit | “Dat is normaal.” · iPhone \| Android |
| Ik weet niet welke privacykeuze ik moet maken | Geen voorschrift · u kiest zelf · helper helpt zoeken, niet beslissen |
| Een deelnemer toont een echt verdacht bericht | Niet op beamer · individueel · niet klikken · bij ernst: officiële hulp |

**Geen** uitgebreide herstelprocedure in C4 — dat hangt af van wat er werkelijk is gebeurd.

**Vaste hulpmethode:**

> Wat ziet u nu? → vragen → uitleggen → aanwijzen → deelnemer doet zelf → pas als laatste kort overnemen
