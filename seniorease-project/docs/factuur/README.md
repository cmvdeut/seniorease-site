# SeniorEase — factuurtemplate

Gebruik dit wanneer een **bibliotheek, buurthuis of stichting** om een officiële factuur vraagt (vóór of na online betaling).

Het Stripe-betalingsbewijs is **geen** formele factuur.

## Bestand

- [`SeniorEase-factuurtemplate.html`](SeniorEase-factuurtemplate.html) — open in de browser, vul in, print of “Opslaan als PDF”.

## Wanneer

1. Organisatie mailt om een factuur (contactformulier of info@seniorease.nl).
2. Vul de template: hun gegevens, factuurnummer, datum, product (los / themapakket / compleet), bedrag incl. BTW.
3. Reeds betaald via Stripe? Noteer betaaldatum of Stripe-referentie en status “reeds betaald”.
4. Stuur de PDF-factuur per e-mail; levering van lesmateriaal blijft via de automatische downloadmail.

## Factuurnummers

Houd zelf een eenvoudige reeks bij, bijv. `SE-2026-001`.

## Bedrijfsgegevens

Vul eenmalig KVK, BTW-id en adres in de template (sectie “Van”) en bewaar een ingevulde masterkopie naast dit bestand.
