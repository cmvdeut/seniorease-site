# 🔍 Facebook Page ID Vinden

## Methode 1: Via Facebook Pagina
1. Ga naar je SeniorEase Facebook pagina
2. Klik op "About" (of "Over")
3. Scroll naar beneden
4. Je ziet "Page ID" - kopieer dit nummer

## Methode 2: Via Graph API Explorer
1. Ga naar: https://developers.facebook.com/tools/explorer/
2. Selecteer je app (of "Graph API Explorer")
3. Klik "Get Token" → "Get User Access Token"
4. Vink aan: `pages_show_list`
5. In het query veld, typ: `/me/accounts`
6. Klik "Submit"
7. Je ziet een lijst met pagina's en hun IDs

## Methode 3: Via Browser
1. Ga naar je Facebook pagina
2. Klik rechts op de pagina → "View Page Source" (of Ctrl+U)
3. Zoek naar "page_id" of "profile_id"
4. Kopieer het nummer
