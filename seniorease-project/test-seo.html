🔍 SEO Test - SeniorEase.nl

Open deze pagina in je browser en test de SEO elementen:

✅ 1. Sitemap Test

Open: http://localhost:3001/sitemap.xml

✓ Sitemap werkt correct!

✅ 2. Robots.txt Test

Open: http://localhost:3001/robots.txt

✓ Robots.txt werkt correct!

📋 3. Metadata Test

Open de homepage: http://localhost:3001

Rechtsklik → "Bekijk paginabron" (View Page Source)

Zoek naar:

  • <title> - Moet "SeniorEase - Handige technologie voor senioren" bevatten
  • <meta name="description"> - Moet beschrijving bevatten
  • <meta property="og:title"> - Open Graph tags
  • <meta name="twitter:card"> - Twitter Card tags

📊 4. Structured Data Test

In de pagina source, zoek naar:

<script type="application/ld+json">

Er moeten 2 JSON-LD scripts zijn:

  • WebApplication schema
  • Organization schema

💡 Tip: Gebruik Google Rich Results Test na deployment

🌐 5. Online SEO Tests (Na Deployment)

Test deze tools na deployment naar productie:

  • Google Rich Results Test - Test structured data
  • Mobile-Friendly Test - Test mobiele weergave
  • PageSpeed Insights - Test snelheid en SEO
  • Schema.org Validator - Test structured data

🔍 6. Browser DevTools Test

Open Developer Tools (F12) en check:

  1. Tab "Elements" → Zoek in <head> naar meta tags
  2. Tab "Console" → Type: document.querySelector('meta[property="og:title"]')
  3. Tab "Network" → Herlaad pagina → Check response headers

✅ Checklist

  • [ ] Sitemap.xml werkt
  • [ ] Robots.txt werkt
  • [ ] Title tag aanwezig
  • [ ] Meta description aanwezig
  • [ ] Open Graph tags aanwezig

📝 Test Commands

Run deze in PowerShell om te testen:

# Test sitemap
curl http://localhost:3001/sitemap.xml

# Test robots.txt
curl http://localhost:3001/robots.txt

# Check HTML source
curl http://localhost:3001 | Select-String "og:title"
